# Следователь: учётные формы

Применяй [общую проверку однозначности](../investigator-2-0/references/03c-legal-grammar.md) только к свободному тексту и неоднозначности заполняемых полей. Печатные легенды, коды и структуру сохраняй; их значение устанавливай по штатной форме и источнику. Полный цикл стилистической редакции и `--legal-style` к карточкам не применяются.

Применяй [профиль учётной формы](../investigator-2-0/references/03a-legal-style-profiles.md): вписывай проверенное значение и код; печатные легенды и содержание кодов не переписывай свободным юридическим языком.

Применяй [общую основу](../investigator-2-0/SKILL.md) и [жанровые правила статкарточек](../investigator-2-0/references/09-genres-stat-cards.md). Установи процессуальное событие и дату решения, затем выбери набор форм по матрице жанра. Имя файла бланка может не совпадать с номером формы; определяй форму по содержанию листа и указанию жанрового раздела.

## Обязательные проверки по задаче

1. До заполнения или содержательной проверки прочти целиком паспорт жанра; установи фактически принятое решение, его дату и применимый набор форм по матрице.
2. Выбери штатные бланки по содержанию, сверь значимые значения и коды с решением и источниками; веди перечень форм с готовностью каждой.
3. Перед выдачей сверь комплектность, реквизиты, заполненные поля и печатные легенды; после массовой замены повтори проверку значений и структуры. Заполнение формы не подтверждает её представление или принятие на учёт.

Комплектность, связанный поиск, контроль после правок и статусы плана — по [общему рабочему порядку](../investigator-2-0/references/27-case-workflow.md). Уже выполненные проверки повторяй только при изменении их оснований; для узкой правки проверяй затронутую часть и целостность результата.


Сверь реквизиты дела, лицо, статью, результат расследования, дату, подписанта и код каждой графы с фактическим процессуальным решением и утверждённым бланком. Не переноси значения из предыдущей карточки без проверки. Для сложных форм правь копию штатного бланка, сохраняя таблицы и печатные легенды; проверь страницы и заполненные поля визуально.

Покажи пользователю состав комплекта и источник каждого значимого значения. Перед выдачей примени [общий контрольный лист](../investigator-2-0/references/17-verification-checklist.md) с учётом особенностей форм.

Выбор формы и кода относится к фактически принятому решению; карточка не доказывает само событие. Если графу нечем подтвердить, оставь её незаполненной в проекте и укажи причину отдельно; не ставь произвольный код.
