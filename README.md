# Investigator 2.0

Комплект из восьми навыков для помощи военному следователю СК России: анализ материалов, проекты документов, переписка, допросы, следственные действия, процессуальные решения, обвинение и учётные формы.

**Публичная обезличенная редакция от 07.10.2026.** Основана на обновлённой рабочей версии. Содержит инструкции, справочники и локальные Python-инструменты. Заполненные документы из реальных дел, персональные реквизиты, токены, модели и готовое Python-окружение не публикуются. Отличия — в [PUBLIC-EDITION.md](docs/PUBLIC-EDITION.md).

Навык готовит проекты и результаты проверки. Подписание, процессуальное принятие решения, направление и регистрация остаются отдельными действиями.

## Установка без Git

1. Выберите **Code → Download ZIP** на странице репозитория и распакуйте архив в отдельную папку.
2. Установите Python **3.12** для Windows с Python Launcher (`py`). Проверьте: `py -3.12 --version`.
3. Откройте PowerShell в распакованной папке:

```powershell
py -3.12 bootstrap.py --profile base
py -3.12 connect_skills.py
```

Либо запустите `start.cmd`: он выполняет оба шага. Двойной щелчок на чистой Windows отдельно не испытывался.

Установщик создаёт `.venv`, устанавливает базовые Python-пакеты из PyPI, проверяет зависимости и сохраняет фактические версии в `.venv/installed-versions.txt`. При повторном запуске готовое окружение используется после проверки версий. Копировать чужую `.venv` не нужно; см. [документацию Python](https://docs.python.org/3/library/venv.html).

`connect_skills.py` создаёт восемь точек входа в `.agents/skills` **внутри проекта**. Глобальные установленные навыки не изменяются, посторонние точки входа не перезаписываются. Откройте папку как проект Codex. При необходимости перезапустите приложение. Это локальное подключение, не установка плагина из каталога. См. [официальную документацию OpenAI](https://learn.chatgpt.com/docs/build-skills).

Восемь каталогов навыков, `run.py`, `bootstrap.py`, `local_config.py` и `requirements` должны оставаться рядом. Копирование одного `SKILL.md` не переносит его зависимости.

## Личные настройки и бланки

При отсутствии собственного `config.local.json` скопируйте образец и заполните необходимые поля:

```powershell
Copy-Item -LiteralPath config.example.json -Destination config.local.json
py -3.12 local_config.py --check
```

- `projects_root` — папка результатов **вне репозитория**, с отдельной подпапкой каждого проекта.
- `templates_root` — папка проверенных локальных бланков.
- `signer` — подтверждённые реквизиты подписанта.
- `correspondence` — контакты и желаемый срок ответа; настройка не устанавливает законный срок.
- `tools` — дополнительные пути к программам и языковым данным OCR.

Пустое поле означает отсутствие значения. Профиль не подтверждает полномочия по делу. Подстановка старой расширенной схемы поддерживается через `SK_CONSTANTS`. Подробности: [настройки](docs/LOCAL-SETTINGS.md), [локальные бланки](docs/LOCAL-TEMPLATES.md).

## Использование

Пример задания после подключения:

> Используй Investigator 2.0. Проект: учебная проверка. Изучи предоставленные источники и подготовь проект запроса. Если предмет или период не определены, уточни их. Не подставляй данные чужого образца.

Другие задачи: сопоставить противоречащие протоколы; составить план допроса со свободным рассказом и уточнениями; проверить проект обвинения с привязкой каждого замечания к первоисточнику.

Инструменты:

```powershell
py -3.12 run.py --offline check_skill.py
py -3.12 run.py --offline check_env.py
py -3.12 run.py --offline extract_docx.py "D:/Учебный проект/пример.docx"
```

Путь условный. Перед незнакомой командой прочитайте `--help`. `--offline` запрещает установку недостающих Python-пакетов, но **не является сетевой песочницей** для сторонних программ и моделей.

## Необязательные возможности

```powershell
py -3.12 bootstrap.py --profile ocr
py -3.12 bootstrap.py --profile audio
```

В зависимости от задачи отдельно требуются Tesseract с русским языком, FFmpeg, Word или LibreOffice, Ghostscript и модели. Базовый установщик их не устанавливает. Доступность проверяет `check_env.py`.

Для gated-модели разделения говорящих пользователь принимает условия доступа и вводит токен локально через `py -3.12 run.py setup_hf_access.py`. Не передавайте токены в чат или GitHub.

Базовый профиль проверен в новом окружении Windows/Python 3.12. OCR, аудио, диаризация и установка на чистую Windows в публичной редакции полностью не испытаны. Для необязательных профилей закреплены прямые зависимости; полного транзитивного lock-файла нет.

## Факты, право и документы

Существенное утверждение связывается с источником и страницей или листом дела. Различаются показания, подтверждённые обстоятельства, версии, правовые выводы и данные образца. Отсутствие материала в предоставленной подборке не доказывает его отсутствия во всём деле.

Локальные правовые справочники — указатели. Историческая отметка «сверено» не подтверждает применимую редакцию. Перед конкретным документом проверяются нормы, вступление изменений в силу и необходимые временные срезы. Непроверенное обозначается в статусе проекта.

Работайте с копиями. Перед выдачей необходимы содержательная сверка, проверка реквизитов и визуальный просмотр всех страниц. Успех скрипта не подтверждает юридическую готовность.

Материалы дела не отправляются в поисковые запросы или сторонние сервисы распознавания. Локальные скрипты не означают, что сам AI-помощник работает офлайн: допустимость передачи содержания зависит от выбранной среды.

## Обновление и публикация

Личный профиль, материалы дел, заполненные бланки, модели и журналы не включаются в Git. Перед обновлением сохраните собственные настройки. Личный комплект требует нового обезличивания перед переносом в публичную ветку.

`.gitignore` не очищает содержимое и не удаляет уже опубликованное из истории. Ручная загрузка через браузер тоже требует проверки состава. См. [документацию Git](https://git-scm.com/docs/gitignore).

Сообщая об ошибке, приложите версию, шаги воспроизведения и синтетический пример. Реальные материалы и токены в публичные обращения не прикладывайте.
