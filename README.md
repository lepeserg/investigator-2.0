# Investigator 2.0

Комплект из восьми навыков для помощи  следователю СК России: анализ материалов, проекты документов, переписка, допросы, следственные действия, процессуальные решения, обвинение и учётные формы.

**Версия 2.0.1. Публичная обезличенная редакция от 09.10.2026.** Основана на обновлённой рабочей версии. Содержит инструкции, справочники и локальные Python-инструменты. Заполненные документы из реальных дел, персональные реквизиты, токены, модели и готовое Python-окружение не публикуются. Отличия — в [PUBLIC-EDITION.md](docs/PUBLIC-EDITION.md).

Навык готовит проекты и результаты проверки. Подписание, процессуальное принятие решения, направление и регистрация остаются отдельными действиями.

## Юридический язык

Основной и семь специальных навыков выбирают [профиль языка по виду документа](investigator-2-0/references/03a-legal-style-profiles.md). Он определяет порядок изложения и сохранение фактов, источников, отрицаний и оговорок после редакции. [24 условных примеров](investigator-2-0/references/03b-legal-style-examples.md) показывают допустимые правки; их сведения не переносятся в дело. Для постановления о привлечении добавлены [правила построения](investigator-2-0/references/07h-charging-writing.md) и [проверка однозначности](investigator-2-0/references/07i-legal-language.md).

Дополнительная механическая проверка:

```powershell
py -3.12 run.py style_lint.py "D:/Учебный проект/проект.docx" --genre postanovlenie --legal-style
```

Режим предупреждает о возможной двусмысленности перечня, границы даты и отсылки к лицу. Скрипт не меняет DOCX и не устанавливает правильное прочтение. Условия, право и факты сверяются по источникам; цитаты и значимые слова допрашиваемого сохраняются. Заимствованный подход к однозначности отмечен ссылкой на `pravo-grammatika` и его MIT-лицензией в комплекте.

## Установка без Git

1. Выберите **Code → Download ZIP** на странице репозитория и распакуйте архив в отдельную папку.
2. Запустите **`start.cmd`** двойным щелчком. Если Python **3.12 x64** отсутствует, установщик предложит загрузить его через WinGet.
3. Выберите набор: **1 — база**, **2 — документы**, **3 — сканы/OCR**, **4 — аудио**, **5 — все компоненты**. Подтвердите установку, когда появится список. Для начала работы с документами подходит пункт 2; остальные возможности можно добавить позже повторным запуском.

Отсутствующие системные программы загружаются через WinGet, Python-библиотеки — из PyPI. Для OCR при необходимости загружаются русские и английские языковые данные и данные определения ориентации страниц. Если WinGet отсутствует, скрипт укажет, как установить App Installer.

**[Подробная инструкция для чистой Windows](docs/WINDOWS-SETUP.md)**: состав наборов, подтверждения, проверка без загрузок, настройка нестандартных путей и ограничения.

Прежний способ для уже установленного Python также поддерживается:

```powershell
py -3.12 bootstrap.py --profile base
py -3.12 connect_skills.py
```

Установщик создаёт `.venv`, устанавливает базовые Python-пакеты из PyPI, проверяет зависимости и сохраняет фактические версии в `.venv/installed-versions.txt`. При повторном запуске готовое окружение используется после проверки версий. Копировать чужую `.venv` не нужно; см. [документацию Python](https://docs.python.org/3/library/venv.html).

`connect_skills.py` создаёт восемь точек входа в `.agents/skills` **внутри проекта**. Глобальные установленные навыки не изменяются, посторонние точки входа не перезаписываются. Откройте папку как проект Codex. При необходимости перезапустите приложение. Это локальное подключение, не установка плагина из каталога. См. [официальную документацию OpenAI](https://learn.chatgpt.com/docs/build-skills).

Сохраняйте структуру распакованного репозитория: восемь каталогов навыков, корневые скрипты и `requirements` должны оставаться рядом. Копирование одного `SKILL.md` не переносит его зависимости.

## Личные настройки и бланки

При отсутствии собственного `config.local.json` скопируйте образец и заполните необходимые поля:

```powershell
Copy-Item -LiteralPath config.example.json -Destination config.local.json
py -3.12 local_config.py --check
```

- `projects_root` — папка результатов **вне репозитория**, с отдельной подпапкой каждого проекта.
- `templates_root` — папка проверенных локальных бланков.
- `signer` — подтверждённые реквизиты подписанта.
- `correspondence` — контакты и желаемый срок ответа; настройка не устанавливает законный срок.
- `tools` — дополнительные пути к программам и языковым данным OCR.

Пустое поле означает отсутствие значения. Профиль не подтверждает полномочия по делу. Подстановка старой расширенной схемы поддерживается через `SK_CONSTANTS`. Подробности: [настройки](docs/LOCAL-SETTINGS.md), [локальные бланки](docs/LOCAL-TEMPLATES.md).

## Использование

Пример задания после подключения:

> Используй Investigator 2.0. Проект: учебная проверка. Изучи предоставленные источники и подготовь проект запроса. Если предмет или период не определены, уточни их. Не подставляй данные чужого образца.

Другие задачи: сопоставить противоречащие протоколы; составить план допроса со свободным рассказом и уточнениями; проверить проект обвинения с привязкой каждого замечания к первоисточнику.

Инструменты:

```powershell
py -3.12 run.py check_skill.py
py -3.12 run.py check_env.py
py -3.12 run.py extract_docx.py "D:/Учебный проект/пример.docx"
```

Путь условный. Перед незнакомой командой прочитайте `--help`. По умолчанию `run.py` ничего не устанавливает: если Python-пакетов не хватает, он останавливается и предлагает запустить `start.cmd`. Разрешить установку из PyPI можно явно: `py -3.12 run.py --install <скрипт> ...`. Прежний ключ `--offline` принимается и ничего не меняет. Отказ от установки **не является сетевой песочницей** для сторонних программ и моделей.

## Необязательные возможности

Повторно запустите `start.cmd` и выберите **3** для сканов или **4** для аудио. Установщик подготовит Python-профиль и недостающие системные программы. Для проверки без установки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup-windows.ps1 -Profile ocr -CheckOnly
```

Если системные программы уже установлены и нужны только Python-библиотеки, остаются команды:

```powershell
py -3.12 bootstrap.py --profile ocr
py -3.12 bootstrap.py --profile audio
```

Набор «документы» предлагает LibreOffice при отсутствии Word. LibreOffice не заменяет Word COM для заполнения полей форм и некоторых статкарточек. Word, доступ к моделям, GPU-драйверы и специальные дополнительные инструменты настраиваются отдельно. `check_env.py` проверяет компоненты выбранных наборов: по умолчанию — по отметкам установщика (без них — только база), явно — через `--profile` (например, `--profile ocr` или `--profile all`). Компоненты невыбранных наборов показываются как неустановленные и не считаются ошибкой. Проверка выбранного набора вместе с системными программами — `setup-windows.ps1 -CheckOnly`.

Для gated-модели разделения говорящих пользователь принимает условия доступа и вводит токен локально через `py -3.12 run.py setup_hf_access.py`. Ключ `--hf-token` у `av_ingest.py` удалён: токен в командной строке виден в списке процессов и истории PowerShell. Токен берётся из Диспетчера учётных данных Windows или переменной `HF_TOKEN`. Не передавайте токены в чат или GitHub.

Базовый профиль проверен в новом окружении Windows/Python 3.12. OCR, аудио, диаризация и установка на чистую Windows в публичной редакции полностью не испытаны. Для необязательных профилей закреплены прямые зависимости; полного транзитивного lock-файла нет.

## Факты, право и документы

Существенное утверждение связывается с источником и страницей или листом дела. Различаются показания, подтверждённые обстоятельства, версии, правовые выводы и данные образца. Отсутствие материала в предоставленной подборке не доказывает его отсутствия во всём деле.

Локальные правовые справочники — указатели. Историческая отметка «сверено» не подтверждает применимую редакцию. Перед конкретным документом проверяются нормы, вступление изменений в силу и необходимые временные срезы. Непроверенное обозначается в статусе проекта.

Работайте с копиями. Перед выдачей необходимы содержательная сверка, проверка реквизитов и визуальный просмотр всех страниц. Успех скрипта не подтверждает юридическую готовность.

Материалы дела не отправляются в поисковые запросы или сторонние сервисы распознавания. Локальные скрипты не означают, что сам AI-помощник работает офлайн: допустимость передачи содержания зависит от выбранной среды.

## Проверки

```powershell
py -3.12 run.py check_skill.py
py -3.12 -m pytest -q tests
```

Если pytest не установлен, те же тесты запускаются командой `.\.venv\Scripts\python.exe -m unittest discover -s tests`. Автоматические тесты охватывают настройки, установку и отказ от неё, подключение навыков, работу с синтетическими DOCX и PDF, проверку окружения по выбранным наборам, сбои внешних программ и контроль целостности языковых данных. Дополнительно проверены запуск проверки базы через Windows PowerShell 5.1, извлечение DOCX, сохранность источника и межмодульные ссылки. Результаты и ограничения — [VALIDATION.md](docs/VALIDATION.md).

## Обновление и публикация

Личный профиль, материалы дел, заполненные бланки, модели и журналы не включаются в Git. Перед обновлением сохраните собственные настройки. Личный комплект требует нового обезличивания перед переносом в публичную ветку.

`.gitignore` не очищает содержимое и не удаляет уже опубликованное из истории. Ручная загрузка через браузер тоже требует проверки состава. См. [документацию Git](https://git-scm.com/docs/gitignore).

Сообщая об ошибке, приложите версию, шаги воспроизведения и синтетический пример. Реальные материалы и токены в публичные обращения не прикладывайте.
