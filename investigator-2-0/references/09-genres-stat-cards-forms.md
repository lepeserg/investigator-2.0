### 09.02.1. Формат и заверение

- Заполняется по форме (табличная разметка).
- Подписи заверителей: следователь, руководитель СО (или его заместитель), военный прокурор — по реальному бланку.
- Дата заполнения, фамилия, инициалы, звание, подпись.

> ⚠ Состав подписантов расходится между пакетами (два: следователь + прокурор; или три: + руководитель/зам. руководителя СО). Финальную редакцию подтверждает человек по бланку и приказу (см. legal_flags).

### 09.02.2. Куда направляется

- Все учётные документы следователь представляет **надзирающему военному прокурору** не позднее суток
  после принятия решения (п. 2.2); тот в течение суток передаёт их в ВПО через АИК «Надзор-WEB» (п. 2.24).
- **Ф-1, Ф-1.2** — при возбуждении и при коде «9». ⛔ Ф-1.1 при возбуждении НЕ выставляется (строка 3 матрицы).
- **Ф-1.1 и Ф-2** — по окончании расследования: при прекращении и **при направлении дела прокурору с ОЗ**
  (п. 2.7 абз. 1). ⚠ В ВПО они уходят **в течение суток после направления дела В СУД** (п. 2.7 абз. 4).
- **Ф-6** — на каждого обвиняемого; ⛔ уходит **в суд вместе с материалами дела**, а не в ВПО (п. 2.7 абз. 5).
- **Ф-3** — при движении дела; при направлении прокурору с ОЗ прокурор в течение суток направляет талон
  в ВПО, проставив код 62 (п. 2.7 абз. 3).
- **Ф-1.3** — при предъявлении первичного обвинения, мере пресечения, розыске, аресте имущества, ДСС.

## 09.03. Ф-1 — СТАТИСТИЧЕСКАЯ КАРТОЧКА НА ВЫЯВЛЕННОЕ ПРЕСТУПЛЕНИЕ

### ● Карточка жанра

**Маршрут.** ⛔ **ПЕРВОЕ ДЕЙСТВИЕ — выбрать путь заполнения (§09.19.4), а не открывать бланк.** Для Ф-1: **Excel-формы ГВП** (§09.18), когда прокурор их принимает: там сквозная логика 40 правил и блокировка выгрузки при ошибках; после выпуска кнопкой обязателен `scripts/post_release_gvp.py` (§09.18.5). Координатный путь §09.16 — **только когда нет ни Word, ни Excel** (Cowork). ⛔ **Бланк-донор — из подпапки `Исходные бланки (с флешки)`** (§09.09): легаси изъято в архив `Старые стат. карты\` — кодов редакции 126/50 оно не несёт (§09.21.6), а `… нов` и `*type-safe*` вдобавок содержат данные чужих дел (§09.10). Единый протокол работы — §09.00, оба контура проверки обязательны.

**Комплект.** Ф-1 не ходит одна. **Возбуждение дела:** Ф-1 + Ф-1.2 (лицо установлено) + Ф-5/Ф-5.5 (потерпевший). **Отказ в ВУД по нереабилитирующим:** Ф-1, Ф-1.1, Ф-1.2, Ф-2 (дело не возбуждалось — учёта преступления и лица ещё нет). ⛔ **При ПРЕКРАЩЕНИИ дела Ф-1 НЕ выставляется** — комплект прекращения — **Ф-1.1 + Ф-2** (§09.01.1); Ф-1 добавляется, только если карты по делу ранее не выставлялись либо нужна корректировка кодом «9». **Новое преступление в ходе следствия:** Ф-1. **Новые данные:** Ф-1 и Ф-1.2 с кодом «9». Полная матрица — §09.01. Ключевые разделы карты — §09.03.2, военная специфика — §09.03.3, коррупционная — §09.03.4, заверение — §09.03.5.

**⛔ Фатальные ошибки.** Пошёл координатным путём при живом Office · «ловушка Times New Roman» — ответы съезжают, §09.15 · **донорские коды оставлены под чужое дело**: графа 2.4 «кто обнаружил» — `01` СК ↔ `41` ВКР ФСБ, пройти по КАЖДОМУ коду (§09.12.2, §09.17) · код выдуман вместо взятого из легенды бланка · графы личности оставлены пустыми или вынесены вопросом вместо наиболее вероятного (§09.20). Специфично для Ф-1: не заполнены **2.8.б** (квалифицирующие признаки) и **2.2** · формат графы 2.8 «причёсан» — замена обнуляет служебный код `O47` и блокирует выпуск · **выпуск кнопкой съедает 2.8.а и 2.8.б** — обязателен `post_release_gvp.py`.

**Гейт.** **Маршрут** (какая форма → какой путь → проверка среды) · **набор карт по ситуации** из §09.01 целиком, а не одна карта · бланк-донор и число полей формы · **Контур 1** — таблица «графа → значение → источник кода» на подтверждение ДО заполнения · **Контур 2** — рендер прочитан глазами либо «Ошибок: 0» у валидатора ГВП.

### 09.03.1. Назначение

Заполняется при возбуждении уголовного дела. Регистрирует сам факт выявленного преступления для статистического учёта.

### 09.03.2. Ключевые разделы

> ⚠ Ниже — ориентировочная реконструкция полей; реальный бланк — сетка ячеек, заполняется по §09.00 (координаты из донора) / §09.11. Нумерацию и точные коды сверять по бланку.

### 09.03.3. Особенности по преступлениям против военной службы

Для статей гл. 33 УК РФ (332, 337, 338, 339 и др.):
- В разделе «способ совершения» — конкретная форма (самовольное оставление, дезертирство, симуляция, подлог).
- В разделе «время совершения» — указать период мобилизации, если применимо.
- В разделе «связь со спецификой воинской службы» — обязательно указать.

### 09.03.4. Особенности по коррупционным преступлениям

Для статей гл. 30 УК РФ (290, 291, 291.1):
- В разделе «способ совершения» — наличный расчёт, безналичный перевод, через посредника, иное.
- В разделе «размер ущерба» — фактически переданная или ожидаемая сумма взятки.
- В разделе «связь с организованной преступностью» — да/нет.

### 09.03.5. Заверение

- Подпись следователя — обязательно.
- Подпись военного прокурора — обязательно (карточка после её заполнения следователем направляется прокурору для заверения).

а также при привлечении в качестве обвиняемого. (Это НЕ «корректировка к Ф-1».)

### 09.04.2. Что заполняет следователь (ключевые поля)

## 09.05. Ф-2 — СТАТИСТИЧЕСКАЯ КАРТОЧКА НА ЛИЦО ПО ОКОНЧЕННОМУ УГОЛОВНОМУ ДЕЛУ

**Маршрут.** Выбери подходящий локальный бланк по виду документа, создай отдельную рабочую копию. Источники и результаты держи вне репозитория.

### ● Карточка жанра

### 09.05.1. Назначение

⛔ **Точное название по п. 1.2 Правил — «статистическая карточка НА ЛИЦО по оконченному уголовному
делу (материалам)»** (приложение 5). Прежний заголовок навыка «о результатах расследования» —
это **Ф-1.1**, другая форма; ошибка исправлена 26.08.2026 по тексту приказа.

**П. 4.5 Правил — для чего служит.** Карточка Ф-2 является основанием:
- для **учёта лица**, дело в отношении которого направлено в суд либо прекращено по
  **нереабилитирующим** основаниям, а также лица, по которому отказано в ВУД по тем же основаниям;
- для **снятия с учёта** ранее зарегистрированного лица, преследование которого прекращено
  по **реабилитирующим** основаниям.

**Одна карточка — на каждое лицо**, и составляется она **одновременно с Ф-1.1** (п. 4.5 дословно:
«составляется одновременно с составлением статистических карточек формы № 1.1 о результатах
расследования совершённых лицом преступлений»).

⛔ **При ПРИОСТАНОВЛЕНИИ Ф-2 не выставляется** — там талон Ф-3 (+ Ф-1.3 при розыске), строка 22
матрицы §09.01. Прежняя запись «заполняется при… приостановлении» изъята.
⚠ При отказе в ВУД по нереабилитирующим основаниям вместе с Ф-2 составляется **Ф-1.2** (п. 4.5).
