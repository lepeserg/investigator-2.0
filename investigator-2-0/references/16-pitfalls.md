# 16. ЧАСТЫЕ ОШИБКИ И ПОДВОДНЫЕ КАМНИ

> Публичная редакция: частные примеры и локальные реквизиты исключены. Применяй основной SKILL.md и 27-case-workflow.md; прежние отметки «сверено», количественные ориентиры и настройки среды не подтверждают актуальность права или готовность текущего документа. Бланки подключаются локально.

Этот файл — для использования при вычитке готового документа и для проверки собственных черновиков. Содержит конкретные ошибки, выявленные в реальной практике {ОРГАН_ПОЛН}, и способы их избежать.

## 16.09. ЧЕК-ЛИСТ ПЕРЕД ВЫДАЧЕЙ ДОКУМЕНТА

Перед тем как показать пользователю готовый документ, прогон по 14 пунктам из `references/17-verification-checklist.md` §17.1, а также:

- [ ] Все ФИО, даты, номера, статьи УК — совпадают с карточкой дела.
- [ ] Тире — только короткое (–).
- [ ] Кавычки — только ёлочки («»).
- [ ] Числа — без падежных окончаний.
- [ ] В/часть — без знака «№».
- [ ] Запрещённые ИИшные обороты — отсутствуют.
- [ ] Подписант — выбран по таблице из `references/01-identity.md` раздел 1.5.
- [ ] Шапка органа — точная: «{ОРГАН_ПОЛН}».
- [ ] Звание {СЛЕДОВАТЕЛЬ_ФИО} — {СЛЕДОВАТЕЛЬ_ЗВАНИЕ}.
- [ ] Если ст. 39 УПК РФ — гриф «СОГЛАСЕН» руководителя.
- [ ] Если ОЗ — гриф «УТВЕРЖДАЮ» прокурора.
- [ ] Все ссылки на нормы УК / УПК — в применимой редакции на юридически значимую дату (обязательная сверка по `references/14-plenums-and-search.md`).
- [ ] ⛔ Каждая правовая посылка аналитического текста сверена с текстом **применяемой ЧАСТИ** — названы статья, часть, редакция, дата сверки (§16.02.7).
- [ ] ⛔ По ст. 286 — в перечне действий нет бездействия (§16.02.8, §26.06).
- [ ] ⛔ Перед созданием файла выведен **листинг папки решения**: документа того же жанра там нет либо решено, какой действующий (§07.05.7 п. 7).
- [ ] ⛔ В документе с повторяющимися блоками ожидаемое число вхождений посчитано ДО правки и сошлось с фактическим (§07.05.9).
- [ ] ⛔ Подписной блок скреплён: генератор — `_glue_block` сам, готовый файл — `{"op": "glue_signature"}` (§16.17, §25.04 п. 11).
- [ ] ⛔ **Сработал признак риска §11.15.7** (Excel-форма ГВП · документ от донора с колонтитулами либо на бланке · длиннее двух страниц или таблица во всю ширину листа) → выполнен **рендер в PDF** и просмотрены страницы: подпись не разорвана, решёток `###` и обрезки нет (§16.17). Ни один признак не сработал — рендер не обязателен: поголовным гейтом он не является (решение владельца 24.08.2026).

## 16.10. ЕСЛИ ОШИБКА ПОВТОРЯЕТСЯ

Если одна и та же ошибка встречается в нескольких документах подряд — это **сигнал** того, что нужно править **этот файл** или соответствующий референс. Сообщи автору навыка через сообщение пользователю: «Замечена систематическая ошибка вида X. Возможно, требуется корректировка skill-файла Y.»

Автор навыка поправит — пользователь перезагрузит обновлённый файл в скилл — ошибка исчезнет.
