## 17.2. ПОСЛЕ ВЕРИФИКАЦИИ — ДОПОЛНИТЕЛЬНЫЕ ПРОВЕРКИ ПО ЖАНРУ

### Для постановления о возбуждении уголовного дела (ВУД)

- [ ] Указан повод (рапорт, заявление, сообщение СМИ) с реквизитами регистрации в КРСП.
- [ ] Указано основание — наличие достаточных данных.
- [ ] Квалификация в резолютивке полностью совпадает с квалификацией в описательной части.
- [ ] В резолютивной части — три обязательных пункта: возбудить, принять к производству, направить копию прокурору.
- [ ] **ПРОВЕРЕНО, что дело на это лицо ещё НЕ возбуждено** (реестр, выделенные материалы, статкарты Ф-1.2, существующие постановления о возбуждении). Дублирующее возбуждение — критическая ошибка.
- [ ] Если дело возбуждается из материалов, выделенных отдельным постановлением, — повод формулировать со ссылкой на реквизиты постановления о выделении, без указания «следователя» как подписанта выделения, если по факту выделение подписывал иной уполномоченный руководитель — сверить, кто фактически подписал выделение, и указать верно.
- [ ] ⛔ **Статус военнослужащего подтверждён первоисточником на дату ДЕЯНИЯ** (по гл. 33 УК это признак специального субъекта) **и на дату решения** (это подследственность) — правило 41.
- [ ] Адрес регистрации фигуранта в анкету постановления о возбуждении вносить только если это принято форматом; при сомнении сверить с образцом (обычно в анкету ВУД — ФИО, дата рождения, место рождения/уроженец, звание, должность, личный номер, дата контракта — без адреса).
- [ ] № уголовного дела стоит в верхнем колонтитуле первой страницы (по правому краю), если так задано форматом.
- [ ] Буква «ё» используется единообразно по всему тексту документа (либо везде «е», либо везде «ё» — не смешивать; сверить с принятым в отделе стилем).

### Для статистических карточек (форма № 1, № 1.2 и аналоги)

- [ ] Квалификация и № дела совпадают с постановлением о возбуждении.
- [ ] Место рождения И место жительства указаны (там, где форма это требует).
- [ ] Личный номер — в своём поле (формат: 2 буквы + 6 цифр, если применимо).
- [ ] Возрастная группа выбрана верно по шкале формы (сверить с действующей инструкцией по заполнению статкарт, не по памяти).
- [ ] Заверитель от руководящего состава указан в должности, предусмотренной формой (сверить точное наименование должности — не путать «руководитель следственного органа» и «заместитель руководителя», если форма различает эти роли).
- [ ] Заверители: следователь + руководитель + прокурор — все трое проставлены по актуальным данным персонального слоя.
- [ ] См. также протокол оформления статкарточек в `references/09-genres-stat-cards.md` (набор по унифицированному приложению к инструкции, ячейки сверяются по донору/эталону, таблица «поле → ячейка» — на подтверждение пользователю перед печатью, финальная сверка — рендер в PDF).

### Для постановления о привлечении в качестве обвиняемого (обвинение)

Обязателен [лист итоговой проверки](07g-pre-issuance-review.md); построение и однозначность — [07h](07h-charging-writing.md) и [07i](07i-legal-language.md).

### Для обвинительного заключения (ОЗ)

- [ ] Гриф «УТВЕРЖДАЮ» прокурора (вверху, в правом краю).
- [ ] Анкета обвиняемого — полная по форме (14 пунктов).
- [ ] По каждой статье обвинения — отдельный блок с фабулой, перечнем доказательств с указанием листов дела и тома.
- [ ] **БЛОКИРУЮЩИЙ: показания раскрыты подробно и по ПЕРВОИСТОЧНИКУ** (§07.05.8, правило 26): содержание
      взято из протокола допроса (Word-файл из папки дела → при отсутствии дословное распознавание
      PDF/скана), а **таблица-гейт «лицо → протокол → файл-источник → Том/л.д. → раскрыто/ПРОБЕЛ»
      ПОКАЗАНА в ответе ДО выдачи**. Источник не найден — задан вопрос пользователю («asking the
      question»), а не написана заглушка.
- [ ] **Нет схлопывающих формулировок** — «дал показания, аналогичные…», «подтвердил ранее данные
      показания», «дал показания об обстоятельствах дела». В показаниях есть даты (и время, где есть).
      Прогнать `scripts/style_lint.py "<ОЗ.docx>" --genre oz`.
- [ ] Перечень лиц, чьи показания изложены, сверен с описью тома и со списком лиц, подлежащих вызову
      (показания есть в деле, но не изложены в ОЗ — тоже пробел, §16.01.5).
- [ ] **БЛОКИРУЮЩИЙ: сверка листов проведена В ОБЕ СТОРОНЫ и ПОКАЗАНА таблицей** (§07.05.7 п. 6):
      опись → ОЗ (что **не процитировано**) И ОЗ → опись (совпадение ссылок). Дробление диапазона
      (в описи 182–183 + 184, в ОЗ 182–184) — расхождение, а не мелочь. ⛔ Не докладывать
      «все листы совпадают» без графы «пропущено».
- [ ] **Начертание**: полужирным — только ввод доказательства («**Показания свидетеля Ф.И.О.**») и
      заголовки блоков; абзац показаний **не стал целиком жирным** после правки (`style_lint.py`
      флаг `абзац-целиком-жирный`; правка — `docx_edit.replace_paragraph(..., lead="…")`).
- [ ] Перечень доказательств защиты, смягчающих/отягчающих обстоятельств, гражданского иска — указан (даже если «отсутствуют»).
- [ ] Список лиц, подлежащих вызову, — приложение.
- [ ] Справка по делу — отдельным блоком в конце с реквизитами для уплаты штрафа (если применимо).
- [ ] Согласование руководителя органа присутствует.

### Для постановления о выделении уголовного дела

- [ ] Первая цифра номера — «4».
- [ ] Основание названо пунктом ч. 1 ст. 154, и оно соответствует фактическому (при п. 4 — есть ли
      соглашение и от какой даты).
- [ ] Есть абзац ч. 4 ст. 154 и формула «включив в него заверенные следователем копии».
- [ ] Срок по ч. 6 ст. 154 назван и обоснован.
- [ ] Квалификация в описательной части, в резолютивной, в статкартах и в тексте соглашения — одна и та же.
- [ ] В перечне нет позиций без даты, кроме тех, где даты нет на бланке.
- [ ] Ни одна позиция не названа обобщённо.
- [ ] Сумма «на N л.» по перечню = числу листов в томах = последнему листу описи.
- [ ] Ни один лист источника не использован дважды.
- [ ] В перечне нет документов, относящихся только к другим лицам.

⚠ Состав и порядок подшивки самих томов — §11.96.5 (гейт), §11.96.6 (что берём и что не берём),
§11.96.7 (позиция описи — по содержимому листа).

### Для протокола допроса (любого вида)

**Дополнительно для допроса ПОДОЗРЕВАЕМОГО / ОБВИНЯЕМОГО (золотой стандарт §06.01.13, правило 29):**

- [ ] **БЛОКИРУЮЩИЙ: есть блок ЛИЧНОСТИ — жизненный путь** (семья и её состав, развитие, образование по
      ступеням, трудовая деятельность и отношение к труду, служба с должностями и званиями, семейное
      положение и иждивенцы, здоровье и учёт у нарколога/психиатра — себя И родственников, алкоголь,
      судимости, круг общения, самооценка). Анкета 14 пунктов его **не заменяет**.
- [ ] **БЛОКИРУЮЩИЙ: по КАЖДОМУ эпизоду закрыты все 11 позиций карточки эпизода** — особенно
      **очевидцы и ВОЗМОЖНЫЕ очевидцы** (кто мог видеть/слышать, кому рассказывал ПОСЛЕ),
      **субъективная сторона** (осознавал, предвидел, желал, мотив, цель) и **оценка своих действий**
      самим допрашиваемым. Незакрытая позиция = вопрос, а не пропуск.
- [ ] Время эпизода — дата либо **узкий диапазон с указанием, чем он ограничен**; место — адрес либо
      маршрут и ориентиры; сумма — с номиналами и **источником происхождения денег**; «за что» — с
      указанием на служебные полномочия и законность действия.
- [ ] **Заданы замыкающие вопросы** («иные эпизоды, лица, суммы?», «что помните неточно?», «кто ещё может
      подтвердить?») и ответы зафиксированы, в том числе отрицательные — принцип «закрытого горизонта».
- [ ] Противоречия с иными доказательствами сняты **на этом же допросе**; версия защиты (долг / подарок /
      провокация / принуждение) отработана на опережение.
- [ ] Прогнан `scripts/style_lint.py "<протокол.docx>" --genre dopros_pod`.

### Для запроса

- [ ] Адресат указан корректно (ФИО, должность, звание, наименование организации).
- [ ] Номер уголовного дела, статус фигуранта, статья УК.
- [ ] Перечень — конкретный, не «иные документы» абстрактно (или с уточнением «иные документы в отношении военнослужащего» при необходимости).
- [ ] Срок исполнения, если требуется, указан.
- [ ] Контактные данные (адрес, email отдела) — актуальные, из персонального слоя.
- [ ] Подписант выбран правильно (следователь по умолчанию; руководитель — для запросов на банковскую тайну, продление и т. п.).
- [ ] **Запрос/поручение:** колонтитул с исполнителем (ФИО, телефон — из персонального слоя) на месте, если так предусмотрено форматом; реквизиты адресата (телефон, факс, эл. почта) — найдены в открытых источниках и актуальны на дату документа.

### Для сопровода прокурору / руководителю вышестоящего органа / суду

- [ ] Корректная норма УПК (ч. 9 ст. 172, ч. 6 ст. 220 и т. п.).
- [ ] Перечень приложений с количеством листов.
- [ ] Подписант — руководитель для сопровода копий постановления о привлечении в качестве обвиняемого и меры пресечения (ч. 9 ст. 172), сопровода уголовного дела с ОЗ (ч. 6 ст. 220), а также писем руководителям вышестоящих следственных органов, председателям судов, должностным лицам аналогичного уровня.
- [ ] **Сопровод прокурору/руководителю вышестоящего органа:** колонтитул с исполнителем, как правило, НЕ ставится — сверить с принятой в отделе практикой.

### Для ходатайств в суд по ст. 165 УПК РФ

- [ ] Указано конкретное основание — что нужно сделать (обыск в жилище, выемка банковской тайны и т. п.).
- [ ] Обоснование с конкретикой — почему именно у этого лица / в этом помещении / в этом банке.
- [ ] Согласие руководителя органа — обязательно.
- [ ] Адресат — название гарнизонного военного суда (по подсудности).
- [ ] Норма указана точно (ст. 165 + конкретная норма по виду действия — 182, 183, 186, 186.1, 115).

### Для меры пресечения в виде заключения под стражу

- [ ] Основания по ст. 97 УПК РФ конкретно обоснованы (может скрыться / продолжить преступную деятельность / угрожать свидетелям / уничтожить доказательства).
- [ ] Невозможность применения более мягкой меры обоснована (с конкретикой).
- [ ] Учтены данные о личности обвиняемого (ст. 99).
- [ ] Подсудность — гарнизонный военный суд по месту производства предварительного следствия.
- [ ] Согласие руководителя следственного органа — обязательно.
- [ ] Срок ходатайства — обычно 2 месяца, в обоснованных случаях больше.
- [ ] ⛔ **Статус лица на дату ходатайства подтверждён первоисточником** (правило 41): от него зависит и место содержания (гауптвахта), и вопрос, не достаточно ли наблюдения командования по ст. 104.
