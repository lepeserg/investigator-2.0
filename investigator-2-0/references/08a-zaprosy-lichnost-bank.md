## 08.02. ЗАПРОС В БАНК ПО СЧЕТАМ ФИЗЛИЦА (базовые сведения — с СОГЛАСИЯ руководителя СО)

**Гейт.** Сверь первоисточники, статус, полномочия, дату, основание и реквизиты. Неизвестное оставь явным пробелом проекта; перед выдачей проверь содержание и оформление.

### ● Карточка жанра

**Гейт.** Проверь первоисточники, статус, полномочия, дату, основание, реквизиты и оформление; неизвестное обозначь как пробел проекта.

**Маршрут.** Гербовый угловик ВСУ по ЦВО, адресат блоком справа; структура — эталон §08.00.3. Донор обязателен (правило 12), таблиц — **0**. Для базовых сведений по счетам физлица отдельно проверь основание согласования в §08.02.1 и ст. 26 ФЗ о банках и банковской деятельности. Норму сверять заново (правило 6).

**Комплект.** Запрос → ответ банка → **протокол осмотра выписки** (`references/18-bank-analysis.md` §18.06.1) → признание вещдоком (§18.06.2). ⛔ Сведения, составляющие **банковскую тайну** сверх базовых, и выемка в банке — только по судебному решению ст. 165 (`references/07d-mery-presecheniya.md` §07.13.5).

**⛔ Фатальные ошибки.** Запрос ушёл без грифа согласования руководителя · через запрос получают то, что требует судебного решения · номер счёта или карты в запросе разошёлся с материалами (правило 32) · Реквизиты адресата выдуманы вместо поиска в открытых источниках (§08.20.8) · **чужая регистрация (№ КУСП, ОМВД) в преамбуле** — правило 25 · подписант взят из донора вместо матрицы (правило 2) · персональные данные фигуранта перенесены из донора (правило 28) · не указан почтовый адрес ВСУ для ответа (§08.00.3 п. 6).

### 08.02.1. Норма (сверено 18.07.2026)

ст. 21, 38, 39 УПК РФ + **ст. 26 Федерального закона «О банках и банковской деятельности» (№ 395-1)**.
⚠ **Справки по счетам и вкладам ФИЗИЧЕСКОГО лица — это банковская тайна.** По ст. 26 ФЗ они выдаются
органам предварительного следствия по делам в их производстве **только при наличии согласия руководителя
следственного органа** (consultant.ru, ст. 26). Поэтому: (1) в основании указывать **ст. 26 ФЗ**, а не
ст. 152 УПК (ст. 152 — о месте производства следствия, к банковской тайне не относится); (2) на запросе —
**гриф «СОГЛАСЕН» руководителя СО** (без него банк вправе законно отказать). *(Найдено аудитом 18.07.2026 —
раньше базовый запрос шёл за подписью следователя без ст. 26 и без согласия.)*

### 08.02.2. Применение

Базовые сведения по счетам физлица (**банковская тайна**, нужно согласие руководителя СО):
- реквизиты счетов клиента, даты открытия, типы;
- подключённые услуги;
- копии договоров банковского счёта/карты.

**Внимание:** для получения **детальной** информации (выписки по операциям, движение, остатки, IP-адреса)
нужно **судебное решение по ст. 165 УПК РФ** — см. `references/07d-mery-presecheniya.md`. То есть: базовые
сведения — согласие руководителя (ст. 26 ФЗ); движение по счетам — суд (ст. 165 УПК).

### 08.02.3. Python-шаблон (базовый запрос)

> **Внимание!** Если требуется получение выписок по операциям, остатков, IP-адресов входов в ЛК и иной банковской тайны — параллельно с запросом готовится **постановление о возбуждении ходатайства в суд по ст. 165 УПК РФ**. **⛔ Фатальные ошибки.** Отправлен «запрос» вместо **требования** · копия ГИАЦ ушла напрямую в Москву · адресат ИЦ выбран по региону фигуранта вместо своего · Реквизиты адресата выдуманы вместо поиска в открытых источниках (§08.20.8) · **чужая регистрация (№ КУСП, ОМВД) в преамбуле** — правило 25 · подписант взят из донора вместо матрицы (правило 2) · персональные данные фигуранта перенесены из донора (правило 28) · не указан почтовый адрес ВСУ для ответа (§08.00.3 п. 6).

**Гейт.** Оба документа названы · подтверждение маршрута ГИАЦ через свой ИЦ · Адресат и по какому правилу он выбран (фиксированный / по месту жительства / по месту службы) · источник реквизитов · подписант · дата живой сверки формулы основания · оформлено письмом-запросом → **хвост по §08.30**; оформлено требованием (§08.21) → хвоста нет, документ оканчивается подписью.

Проверка ведётся **двумя документами** — по региональному учёту (ИЦ МВД по субъекту) и по федеральному учёту (ГИАЦ МВД России), оба направляются через региональный ИЦ.
