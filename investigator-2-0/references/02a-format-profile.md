# 02a. Профиль оформления

Для адресной правки сохраняй оформление выбранного файла. Для нового документа сначала выбери подходящий подтверждённый локальный бланк. Правила [формата](02-format.md) применяются с учётом жанра и действующих требований; профиль донора не является универсальной нормой.

- Базовые параметры генератора: Times New Roman 13, одинарный интервал, абзацный отступ 1,25 см; поля задаются профилем. Это технические настройки, их применимость проверяется к документу.
- Даты и время сверяй по источнику. Незавершённые поля фактического действия заранее не заполняются.
- Заголовки, связки, таблицы, нумерация и подписи сохраняют структуру выбранной формы. Не удаляй таблицы ради заданного количества.
- Гербовый угловик и адресат справа — по локальному бланку. Нельзя воспроизводить чужую серию, номер, подпись или печать.
- Телефон, адрес ответа, подписант и код подразделения берутся из подтверждённых локальных данных. Электронную почту без указания пользователя не добавляй.
- Перед выдачей перечитай итоговый файл и осмотри все страницы. Количество страниц, абзацев и таблиц — диагностические показатели, а не норматив полноты.
