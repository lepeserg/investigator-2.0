### 09.18.9. ⛔ ГРАФА 2.7 (ФАБУЛА) — ФОРМАТ БЕРЁТСЯ ИЗ ЭТАЛОНА, а не из бланка ★★

Графа 2.7 «Описание преступления» — объединённая ячейка **`D40:I40`**.

| Параметр | Эталон | Как было у нас |
|---|---|---|
| Кегль | **8 пт** | 14 пт |
| Начертание | **обычное** | полужирный |
| Выравнивание по горизонтали | **по ширине** | по центру |
| Выравнивание по вертикали | **по верхнему краю** | по центру |
| Высота строки | **106,5** | сначала 17,4, потом «исправлено» на 140 |

⛔ **Диагноз был неверным дважды.** Сперва фабулу сочли не помещающейся из-за высоты строки и
раздули высоту до 140 пт — карта стала **трёхстраничной**, а текст всё равно обрезался: при кегле
14 в графу физически влезает **семь строк**, и остаток Excel отбрасывает **молча**. Причина была не
в высоте, а в **формате**: настройки брались из бланка по умолчанию вместо живого образца.

⛔ **Это ВТОРОЙ случай одной и той же ошибки в одной сессии** — первый со званиями (§09.18.10).
Оба раза справочные настройки бланка предпочли донору. Правило 44: **донор сильнее справочника**.

⚠ **Автоподбор высоты на объединённой ячейке не работает и об этом не сообщает** — вызов
отрабатывает без ошибки и не меняет ничего. Но лечение — **не** ручной расчёт высоты: считать
бесполезно, пока формат чужой. Сначала формат эталона, потом смотреть глазами.

### 09.18.10. ⛔ ВИЗУАЛЬНЫЙ КОНТРОЛЬ — ЭКСПОРТ В PDF И ОТРИСОВКА, а не расчёт

Для docx-документов гейт требует рендер и сверку глазами; **для Excel требование то же и по той же
причине**. ⛔ **Расчёт по формуле не заменяет просмотр:** 19.08.2026 расчёт высоты дал «140 пт,
поместится» — а глазами было видно, что текст обрезан и карта разъехалась на три страницы.

**Порядок:** выгрузить карту → экспортировать в PDF → отрисовать страницы → посмотреть. Проверяются
четыре вещи:

1. **нет `###`** — карта уходила владельцу с решётками: столбец `J` шириной 8,3 не вмещал даты.
   ⛔ **Через COM `###` не ловится вовсе:** `Range.Text` на узкой ячейке возвращает нормальное
   значение, а не решётки. Только рендер.
   ⚠ **Ширину `J` довести до 15,5** — при НАСТОЯЩИХ (числовых) датах, иначе решётками печатаются даты
   подписей `J89`/`J91` (Ф-1) и `J66`/`J68` (Ф-1.2). Текстовая дата этот дефект прячет: строка
   перетекает в соседнюю ячейку и выглядит нормально — то есть исправление дат по §09.18.7
   **обнажает** узкий столбец;
2. **длинный текст виден ЦЕЛИКОМ** — до последних слов фабулы, а не до седьмой строки;
3. **число страниц как у эталона** (Ф-1 — две, Ф-1.2 — одна): лишняя страница = формат разъехался;
4. **даты совпадают с исходными** — постгейт §09.18.7.

### 09.18.11. Звания — СОКРАЩЁННЫЕ, как в доноре (правило 44)

В карте пишутся **сокращённые звания со строчной буквы**: `л-т юст.`, `ряд.`, `ст. сержант`,
`п-к юст.`, `п/п-к юст.`. 19.08.2026 сокращения из донора были заменены на полные названия из
справочника внутри бланка — `Лейтенант юстиции`. Владелец требовал обратного: «воинские звания
должны быть сокращённые».

⛔ **Ошибка приоритета источника, а не непонимания реплики.** Замечание «звания с маленькой буквы»
допускало два прочтения, но разрешить его можно было **без вопроса** — посмотреть в донор.

### 09.18.12. ⛔ ПУСТАЯ ГРАФА В ДОНОРЕ ≠ ГРАФА НЕ НУЖНА (Ф-1.2, п. 2.2)

⚠ Связка с правилом 41: статус берётся **на дату документа и по первоисточнику**; от него зависит
не только выбор нормы, но и то, какие графы карточки подлежат заполнению.

### 09.18.13. ⛔ ПАРАМЕТРЫ ПЕЧАТИ — С ЭТАЛОНА. `FitToPagesTall` — главная ловушка

| | Ф-1 | Ф-1.2 |
|---|---|---|
| Разрыв страницы | строка **47** | строка **43** |
| `FitToPagesWide` / `FitToPagesTall` | 1 / **False** | 1 / **False** |
| Поля сверху и снизу | 0,75″ | **0,39″** |
| Страниц в готовой карте | **2** | **2** |

⛔ **`FitToPagesTall = 1` впихивает всю карту на ОДНУ страницу, сжимая её.** У бланка Ф-1.2 стоит
именно так — и карта выходит одностраничной вместо двух. Это не косметика: сжатая карта не совпадает
с эталоном, который принимает прокуратура.

⚠ **Параметры печати слетают** при `SaveCopyAs` и удалении служебных листов — задавать их **заново**
в конце выгрузки, вместе с форматом графы описания (§09.18.9).

```python
ps = ws.PageSetup
ps.Zoom = False
ps.FitToPagesWide = 1
ps.FitToPagesTall = False
ps.TopMargin = ps.BottomMargin = 0.39 * 72      # Ф-1.2; для Ф-1 — 0.75 * 72
ws.ResetAllPageBreaks()
ws.Rows(43).PageBreak = -4135                    # xlPageBreakManual; для Ф-1 — строка 47
```

### 09.18.15. Грабли COM — сводка

  чистить `%TEMP%\gen_py`.
- ⛔ **`wb.Protect(пароль)` ломает файл** — книга перестаёт открываться через COM, лечится только

### 09.18.18. ⛔ ПАНЕЛЬ «ПРОВЕРКА КАРТОЧКИ» — ЧИТАЕТСЯ ФОРМУЛАМИ. `CheckCard` НЕ ЗАПУСКАТЬ ★

| Что читать | Где | Что там |
|---|---|---|
| Итог | **`M2`** | `="Ошибок: "&КолОшибок&…` |
| Расшифровка | **`M5:O20`** | `INDEX/MATCH` по `Прав_Пункт` / `Прав_Уровень` / `Прав_Сообщение` |

**Порядок:** открыть книгу → `xl.CalculateFull()` → прочитать `M2` и `M5:O20` → показать в ответе
пункт, уровень и текст каждой строки.

```python
wb = xl.Workbooks.Open(path, UpdateLinks=0)
ws = wb.Worksheets("Ф1стр1")                 # для Ф-1.2 — «Ф1.2стр1»
xl.CalculateFull()
print(ws.Range("M2").Text)                   # «Ошибок: 0 Предупреждений: 0»
for r in range(5, 21):                       # M5:O20 — пункт / уровень / сообщение
    punkt, uroven, soobshchenie = (ws.Cells(r, c).Text for c in (13, 14, 15))
    if punkt.strip():
        print(punkt, uroven, soobshchenie)
```

⚠ Панель живёт в технической зоне `L:P` — читать её надо **до** удаления зоны при выпуске (§09.18.8,
шаг 1).

⛔ «Ошибок: 0» **не доказывает исправность карты**: пп. 3–6 гейта §09.18.16 формулами не ловятся
вовсе, а испорченный номер дела в `O48` панель пропустила (§09.18.19). Статусная запись — не факт,
проверять на файле (правило 46).

### 09.18.19. ⛔ СЛУЖЕБНЫЕ `O47` / `O48` — ФОРМУЛЫ. ЗНАЧЕНИЯМИ НЕ ЗАТИРАТЬ ★★

Ячейки правее карты — не «пустые технические поля», а формулы выгрузки в DBF:

| Форма | Ячейка | Формула |
|---|---|---|
| Ф-1 | `O47` | `=IFERROR(INDEX(Таблица1[Код статьи],MATCH(D43,Таблица1[Статьи],0)),"")` — код статьи по строке 2.8.а |
| Ф-1 | `O48` | `=SUBSTITUTE(F7,".","")` — номер дела без точек |
| Ф-1.2 | `O47` | `=SUBSTITUTE(F7,".","")` — номер дела без точек |

**Как правильно:** заполнять **только** `F7` и строку 2.8.а; служебные ячейки пересчитаются сами.
⛔ Не «причёсывать» формат 2.8.а — это обнуляет `O47` (§09.18.5).

**Постгейт:** прочитать назад `.Formula` (должна начинаться с `=`) и `.Text` служебной ячейки,
сверить цифры **посимвольно** с номером дела без точек.

```python
assert ws.Range("O48").Formula.startswith("="), "формула затёрта значением"
assert ws.Range("O48").Text == case_no.replace(".", ""), "номер дела испорчен"
```
