## 09.00. ЕДИНЫЙ ПРОТОКОЛ РАБОТЫ СО СТАТКАРТАМИ (обязателен, шаги не пропускать)

> ⓘ Не жанр — единый протокол работы со статкартами — сквозная методика, а не форма. Карточка жанра не требуется.

Статкарты — табличные бланки с жёсткими координатами ячеек. Угадывание ячеек «по памяти» и пропуск проверки = повторяющийся брак (значение не в ту ячейку, не тот набор карт, неверный код/формат, порча бланка). На ЛЮБУЮ статкарту работать строго по этому протоколу, шаги не пропускать:

1. **Набор карт — только по Приложению 13** (см. §09.01, матрица «ситуация → карточки»). ⛔ **Прекращение = Ф-1.1 + Ф-2**; Ф-1 и Ф-1.2 добавлять только если карты по делу ранее не выставлялись либо нужна корректировка. ⛔ **Имя файла бланка ≠ форма** (`Ф-11 нов` = Ф-1.1, `Ф-13 нов` = Ф-1.3, `Ф-12 нов` = пакет Ф-1 + Ф-1.2) — карта соответствия **§09.09**; карта на лицо = **Ф-1.2**, рабочий бланк `Исходные бланки (с флешки)\Ф-12.docx`. ⛔ Бланки берутся из подпапки «Исходные бланки (с флешки)», файлы корня — легаси (§09.21.6).
2. **Координаты ячеек — из РЕАЛЬНОГО донора, НЕ по памяти.** Сетку конкретного бланка получать через `make_statcards.py grid "<бланк>"` (дамп таблиц `[t][r][c] → текст ячейки`) и `verify` (проверка, что координаты карты попадают в ожидаемые подписи полей). Координатные карты доноров разных отделов расходятся (см. legal_flags) — свою карту всегда брать из своего донора.
3. **Контур 1 (согласование).** Показать пользователю таблицу «поле → значение → ячейка `[t][r][c]`» на подтверждение ПЕРЕД заполнением.
4. **Заполнение — на копии донора** через `fill_card` / `docx_edit` (не в оригинале бланка).
5. **Контур 2 (сверка).** Отрендерить `make_statcards.py pdf "<карта>"`, прочитать PDF собственным зрением и сверить с донором (значения по ячейкам, число страниц, следы шаблона) ПЕРЕД выдачей.

> Пути к донорским бланкам, генератору и рендеру (LibreOffice/`soffice`) задаёт **персональный слой** (см. `01-identity.md` / константы). В ядре — только правила протокола, без машинных путей.

### 09.01.1. ⛔ ПРЕКРАЩЕНИЕ = Ф-1.1 + Ф-2 — ЭТО НОРМА, А НЕ ПРАКТИКА

Три независимых источника, сверенных по оригиналу приказа 26.08.2026:

2. **П. 4.5 Правил** — «Статистическая карточка формы № 2 составляется **одновременно** с
   составлением статистических карточек формы № 1.1 **о результатах расследования совершенных
   лицом преступлений**».
3. **АЛГОРИТМ (приложение 13), строки 20–21** — прекращение по реабилитирующим: Ф-1.1 + Ф-2;
   по нереабилитирующим: Ф-1.1, Ф-1.2, Ф-2, Ф-5, Ф-5.5 **с оговорками** (см. ниже).

**Ф-1 как карта на выявленное преступление при прекращении не выставляется** — она выставлена при
возбуждении (п. 2.5). ⚠ **Но не «никогда»:** п. 2.4 Правил — «Для снятия данных преступлений с учета
составляется статистическая карточка формы № 1.1 и **при необходимости – статистическая карточка
формы № 1 с измененной фабулой** оставшегося на учете преступления»; то же даёт Ф-1 с кодом «9»
(таблица ниже). ⛔ Основание такой Ф-1 называть в гейте прямым текстом.
Прежний набор навыка «Ф-1, Ф-1.1, Ф-1.2, Ф-2» — это **п. 2.8 Правил про ОТКАЗ В ВУД** («при вынесении
постановления об отказе в возбуждении уголовного дела по нереабилитирующим основаниям статистические
карточки формы № 1.1, 1.2, 2 … составляются одновременно со статистической карточкой формы № 1»).
Там дела не было, учёта преступления и лица ещё нет — потому и полный комплект. ⛔ Перенос этого
правила на прекращение возбуждённого дела — та самая ошибка, которую навык носил.

**Когда к Ф-1.1 + Ф-2 добавляются другие карты** (дословные оговорки матрицы):

| Карта | Добавляется |
|---|---|
| **Ф-1.2** | только на лицо, **по которому ранее такая карточка не составлялась**. По делу, возбуждённому в отношении конкретного лица, она уже выставлена при ВУД — потому в корпусе владельца её нет ни в одном из восьми комплектов |
| **Ф-5 / Ф-5.5** | только на пострадавших, **не признанных потерпевшими** в ходе следствия |
| **Ф-1 / Ф-1.2 с кодом «9»** | если нужна **корректировка** ранее учтённых данных (§09.13.2) |

⛔ Основание добавления называть в гейте прямым текстом («Ф-1.2 ранее не выставлялась» /
«корректировка кодом 9»). Нет основания — комплект из двух карт.

**Частичное прекращение** (решение по отдельным преступлениям до окончания дела): Ф-1.1 выставляется
с признаком **«2 — дополнительная»**, а не «1». П. 4.2 Правил: «По одному уголовному делу может быть
составлено несколько карточек формы № 1.1 с кодом „2“, при этом они должны быть представлены до
основной карточки **(при принятии решения до окончания расследования уголовного дела)** либо
одновременно с ней». Спрашивать: решение по всему делу или по эпизодам.
