## ПАСПОРТ ЖАНРА — ЧИТАТЬ ЦЕЛИКОМ ПЕРЕД ЛЮБОЙ РАБОТОЙ

⛔ **Паспорт читается ПОЛНОСТЬЮ и ДО первого действия** ([SKILL.md, «Границы маршрутов»](../SKILL.md#границы-маршрутов)). Тело файла — выборочно, по
якорям. Главная развилка жанра решается ДО сборки: нужно ли судебное решение по ст. 165 УПК.

### 1. МАРШРУТ — ПЕРВОЕ ДЕЙСТВИЕ: определи основание

| Действие | Основание | Судебное решение |
|---|---|---|
| Осмотр места происшествия | ст. 176, 177 УПК; до ВУД — ч. 2 ст. 176 | нет |
| Осмотр предметов и документов | ст. 176, 177 УПК | нет |
| **Выемка** — местонахождение **известно** | постановление следователя, ст. 183 | нет |
| **Выемка в банке** (банковская тайна), у адвоката, в жилище без согласия | ст. 183 + **ст. 165** | ⛔ **ДА** — `references/07d-mery-presecheniya.md` §07.13.5 |
| **Обыск** — местонахождение **НЕ известно**, нежилое помещение | постановление следователя, ст. 182 | нет |
| **Обыск в жилище** | ст. 182 + **ст. 165** | ⛔ **ДА** — §07.13.4; исключение — случаи, не терпящие отлагательства, с уведомлением суда в течение 24 часов |

⛔ **Только правка донора-бланка, генератор запрещён** (правило 12): протоколы осмотра, выемки и
обыска несут таблицу понятых. Ожидаемое число таблиц — **от 1**. Ноль таблиц = взят не бланк, стоп. ⚠ Счёт таблиц — по **ДОНОРУ**; в готовом протоколе единоличного осмотра без понятых таблиц ноль, потому что таблица понятых снята (§06.09.4).

### 2. СОСТАВ — что обязано выйти вместе

| Ситуация | Комплект |
|---|---|
| Выемка | постановление о производстве выемки (§06.12) → протокол выемки (§06.11) → бирки на изъятое → при необходимости постановление о признании вещдоком (`references/06e-veshchdoki.md` §06.17) |
| Обыск в жилище | постановление о возбуждении ходатайства (§07.13.4) → судебное решение → протокол обыска → бирки → вещдоки |
| Осмотр с изъятием | протокол осмотра → бирки → осмотр предметов (§06.10) → постановление о признании вещдоком |
| Изъят носитель для экспертизы | + **контрольный образец носителя** (`references/06e-veshchdoki.md` §06.21.3) — без него экспертное учреждение вернёт материалы |

### 3. ФАТАЛЬНЫЕ ОШИБКИ ЖАНРА

Фатальные ошибки собраны в поле «⛔ Фатальные ошибки» карточки жанра каждого раздела: §06.09, §06.10, §06.11, §06.12, §06.13. Перед сборкой прочитай карточку выбранного раздела.

### 4. ПРАВИЛА ЯДРА, КОТОРЫЕ ЗДЕСЬ СРАБАТЫВАЮТ

**12** донор-бланк · **13**, **13-bis** следы донора и вычитка по существу · **24** безопасная
запись · **28** персональные данные участников · **32** провенанс изъятого · **37** оформительские
преференции · **38** следы ИИ.

### 5. ГЕЙТ — ПОКАЗАТЬ В ОТВЕТЕ ДО СБОРКИ

1. **Основание** из таблицы блока 1: нужно ли судебное решение по ст. 165 — да/нет и почему.
2. **Донор:** имя файла + число таблиц.
3. **Понятые** — двое с данными, либо обоснование ч. 1.1 ст. 170 со сверкой.
4. **ТС фиксации** — марка, модель, серийный номер.
5. **Что изымается и что с этим дальше** — комплект из блока 2 (бирки, вещдоки, контрольный образец).
6. **Если осматривается носитель информации** — тип, метка и серийный номер тома, полученные
   машинно (`GetDriveTypeW`, §06.10.5), и подтверждение, что это **сам носитель, а не копия**.
7. Дата живой сверки ст. 165, 170, 176, 182, 183 УПК.
