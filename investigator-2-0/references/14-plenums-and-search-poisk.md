### 14.04.3. Практическая навигация по pravo.gov.ru

**pravo.gov.ru — официальный портал правовой информации**

Это **главный источник** для проверки действующей редакции любого федерального закона / кодекса / указа Президента / постановления Правительства.

#### Что искать на pravo.gov.ru

- Действующие редакции федеральных законов;
- Действующие редакции кодексов (УК, УПК, КоАП, ГК, ГПК и др.);
- Указы Президента;
- Постановления Правительства;
- Официальное опубликование изменений.

#### Как найти статью УК / УПК

1. Зайти на pravo.gov.ru.
2. В поиске ввести: «Уголовный кодекс Российской Федерации» / «Уголовно-процессуальный кодекс».
3. Открыть **действующую редакцию** (не первоисточник 1996 / 2001 года).
4. Перейти к нужной статье через поиск по тексту (Ctrl+F).

#### Где найти дату актуальности редакции

На странице кодекса / закона в начале текста — блок:
> «Действующая редакция от {ДД.ММ.ГГГГ}»

Ниже — список ФЗ, которыми вносились последние изменения.

#### Поисковые запросы

```
site:pravo.gov.ru "Статья 337 УК РФ" действующая редакция
```

```
site:pravo.gov.ru "Уголовный кодекс" "ст. 290"
```

### 14.04.4. Практическая навигация по vsrf.ru

**vsrf.ru — Верховный Суд РФ**

#### Что искать

- Постановления Пленума ВС РФ (включая по уголовным делам);
- Обзоры судебной практики (ежеквартальные и ежегодные);
- Обзоры по конкретным темам;
- Информационные письма.

#### Раздел «Документы»

На vsrf.ru — раздел «Документы» → «Постановления Пленума и обзоры судебной практики» → фильтр по году.

Альтернатива: «Документы» → «Решения Пленума».

#### Поисковые запросы

```
site:vsrf.ru "Постановление Пленума" "от 18.05.2023"
```

```
site:vsrf.ru "О практике рассмотрения судами уголовных дел"
```

```
site:vsrf.ru "Обзор судебной практики" "2024"
```

### 14.04.5. Практическая навигация по sudact.ru

**sudact.ru — судебная практика судов общей юрисдикции**

Бесплатный агрегатор приговоров, постановлений, апелляционных определений.

#### Что искать

- Конкретные приговоры по интересующей статье УК;
- Постановления судов о мерах пресечения;
- Апелляционные определения;
- Решения по ходатайствам по ст. 165 УПК РФ.

#### Структура ссылки

Каждый документ на sudact.ru имеет постоянную ссылку. Можно фильтровать по:
- Статье УК;
- Региону;
- Типу решения (приговор / определение / постановление);
- Году.

#### Поисковые запросы

```
site:sudact.ru "ч. 5 ст. 337 УК РФ"
```

```
site:sudact.ru "приговор" "ст. 290 УК РФ" {РЕГИОН}
```

```
site:sudact.ru "постановление" "обыск в жилище" "ст. 165 УПК РФ"
```

### 14.04.6. Практическая навигация по consultant.ru (открытая часть)

**КонсультантПлюс — открытая часть**

В **открытой** (бесплатной) части КонсультантПлюс доступно:
- Полные тексты Конституции РФ, кодексов (УК, УПК, КоАП, ГК, ГПК, СК, НК), большинства федеральных законов;
- Постановления Пленума Верховного Суда РФ;
- Постановления Пленума Высшего Арбитражного Суда РФ;
- Указы Президента РФ;
- Постановления Правительства РФ.

В **платной** (закрытой) части — комментарии, судебная практика подробная, региональные акты, корпоративная документация. Открыто **не** доступно.

#### Где найти дату актуальности на consultant.ru

Внутри документа — после названия статьи / закона:
> «(в ред. Федеральных законов от {ДД.ММ.ГГГГ} N {номер}, ...)»

Это перечень ФЗ-изменений. Последний ФЗ в списке — последняя редакция.

#### Поисковые запросы

```
site:consultant.ru "ст. 337 УК РФ"
```

```
site:consultant.ru "Постановление Пленума ВС РФ от 18.05.2023 N 11"
```

```
site:consultant.ru "Уголовно-процессуальный кодекс" "ст. 162"
```

#### Особенности

- На consultant.ru удобный поиск по тексту, есть гиперссылки между статьями.
- Примечания к статьям УК — отображаются в конце статьи (раскрыты).
- Быстрый переход между частями статьи через якоря.

### 14.04.7. Практическая навигация по garant.ru (открытая часть)

**Гарант — открытая часть**

Аналогично КонсультантПлюс, в **открытой** части доступно:
- Кодексы РФ;
- Федеральные законы;
- Постановления Пленума ВС РФ;
- Указы Президента;
- Постановления Правительства.

В **платной** части — комментарии Гаранта (отдельный продукт), специализированные базы. Открыто **не** доступно.

#### Где найти дату актуальности на garant.ru

В верхней части документа — заголовок:
> «Действующая редакция (актуально на {ДД.ММ.ГГГГ})»

или

> «(с изменениями и дополнениями от {ДД.ММ.ГГГГ})»

#### Поисковые запросы

```
site:garant.ru "ст. 290 УК РФ"
```

```
site:garant.ru "Постановление Пленума" "о практике рассмотрения судами уголовных дел"
```

#### Особенности

- На garant.ru есть удобная функция «Паспорт документа» (но открыта частично — основные реквизиты и история редакций).
- При просмотре статьи можно увидеть **архив редакций** (полезно при работе с делами, где деяние совершено в более ранний период — нужна редакция, действовавшая на момент деяния).

### 14.04.8. Стратегия — какой источник в каком случае

| Задача | Лучший источник |
|---|---|
| Проверка действующей редакции статьи УК / УПК | pravo.gov.ru (приоритет) → дублирование на consultant.ru |
| Проверка постановления Пленума | vsrf.ru → consultant.ru |
| Поиск судебной практики (приговоры, апелляции) | sudact.ru |
| Быстрый поиск с удобной навигацией | consultant.ru или garant.ru |
| Проверка истории редакций (для дел с давним временем) | garant.ru (раздел «Архив редакций») |
| Толкование сложных норм через Пленумы | vsrf.ru |
| Найти конкретный ФЗ-изменение | publication.pravo.gov.ru |

### 14.04.9. Сложные случаи — поиск редакции, действовавшей на дату деяния

Если преступление совершено, например, в 2021 году, а закон с тех пор изменился — для квалификации применяется **редакция, действовавшая на дату деяния** (если новая редакция не улучшает положение обвиняемого; иначе применяется новая по ст. 9, 10 УК РФ).

#### Где найти историческую редакцию

1. **garant.ru** — раздел «Архив редакций» в карточке закона.
2. **consultant.ru** — переключатель между редакциями (если доступен).
3. **publication.pravo.gov.ru** — официальные публикации каждого ФЗ-изменения.

При сомнении в применимой редакции — обратись к пользователю:
> «Уточняю: преступление совершено {ДД.ММ.ГГГГ}. На эту дату действовала редакция от {ДД.ММ.ГГГГ}. Использую её или новую?»

### 14.04.10. Что НЕЛЬЗЯ использовать

| Сайт | Причина |
|---|---|
| Wikipedia | Не источник права |
| Юридические форумы (forum.garant.ru, и т. п.) | Мнения участников, не нормативный источник |
| Юридические блоги | Авторская интерпретация |
| Сайты юридических фирм | Маркетинг, не нормативный источник |
| ИИ-сервисы (включая Claude, ChatGPT и иные) — для **получения** норм | Возможны устаревшие или галлюцинированные данные |
| Социальные сети | Не источник права |
| Новостные сайты (РИА, ТАСС и т. д.) | Журналистская интерпретация, возможны искажения |

## 14.05. АЛГОРИТМ ПОИСКА НОРМЫ

### Шаг 1. Возьми ориентир из кэша

Открой `references/12-uk-cache.md` (для УК) или `references/13-upk-cache.md` (для УПК). Кэш — это **ориентир** для квалификации и навигации, **но не основание цитировать норму**.

### Шаг 2. Сверь действующую редакцию по белому списку — ВСЕГДА

Перед составлением **любого** документа сверяй точную формулировку и редакцию применяемой нормы по белому списку (приоритет pravo.gov.ru) — независимо от того, есть статья в кэше или нет, помечена она ★ или нет. Сверка обязательна для каждого документа, а не только «при сомнении». **Только** по белому списку. Зафиксируй дату сверки.

### Шаг 3. Формат запросов в web search

#### Для проверки действующей редакции статьи УК

```
site:pravo.gov.ru "Статья 337 УК РФ"
```

или

```
site:consultant.ru "ст. 337 УК РФ" редакция
```

#### Для проверки действующей редакции статьи УПК

```
site:pravo.gov.ru "Статья 162 УПК РФ"
```

#### Для поиска постановления Пленума

```
site:vsrf.ru "Постановление Пленума" "о практике рассмотрения уголовных дел о преступлениях против военной службы"
```

```
site:vsrf.ru "Постановление Пленума ВС РФ от 09.07.2013 N 24"
```

#### Для поиска обзора практики

```
site:vsrf.ru "Обзор судебной практики" 2024
```

#### Для поиска конкретного прецедента

```
site:sudact.ru "ч. 5 ст. 337 УК РФ" "период мобилизации"
```

```
site:sudact.ru "приговор" "ст. 290 УК РФ" {РЕГИОН}
```

#### Для толкования (Гарант / Консультант, открытое)

```
site:consultant.ru "ст. 291.1 УК РФ" комментарий
```

```
site:garant.ru "ст. 158 УК РФ" примечание
```

### Шаг 4. Проверка актуальности редакции

В тексте статьи на pravo.gov.ru или consultant.ru ищи:
- **Дату последней редакции** — обычно в подстрочном знаке или вверху страницы.
- **Перечень изменений** — список ФЗ, которыми вносились изменения.
- Если редакция датирована старее 2 лет — дополнительно проверь поиском «изменения [статья] УК РФ {текущий год}».

Если статья помечена ★ в кэше — обязательно проверь по pravo.gov.ru, не сокращай и не доверяй кэшу.

### Шаг 5. Цитирование в документе

- Цитируй **дословно**. Не пересказывай нормы своими словами.
- Указывай источник: «по состоянию на ДД.ММ.2026 на pravo.gov.ru».
- Если есть пленум — приводи реквизиты:
  > «постановление Пленума ВС РФ от 18.05.2023 № 11 «О практике рассмотрения судами уголовных дел о преступлениях против военной службы»».

### Шаг 6. При противоречивых результатах

Если разные источники показывают разную редакцию или содержание — **приоритет pravo.gov.ru** (официальное опубликование). Сообщи пользователю о расхождении.

## 14.07. КОГДА ЗАПРАШИВАТЬ У ПОЛЬЗОВАТЕЛЯ

### Если речь о ведомственных (ДСП) актах

Если пользователь спрашивает о специфической ведомственной норме (приказ СК России, указание Председателя СК) — это ДСП-документы, в открытом доступе их нет. **Спроси у пользователя** реквизиты или содержание, не выдумывай.

### Если речь о новейших изменениях

Если идёт обсуждение нормы, по которой возможны изменения, и поиск в pravo.gov.ru возвращает редакцию старее текущего года — **спроси пользователя**: «Эта редакция действующая на сегодня? Я не обнаружил более свежей в открытом доступе.»

### Если речь о практике конкретного суда

Если нужна практика **конкретного** гарнизонного военного суда (например, {гарнизонный военный суд по месту дислокации}) — спроси пользователя, есть ли у него прямые ссылки или реквизиты приговоров.

## 14.08. ЧТО НЕЛЬЗЯ

### Никогда:

1. **Цитировать нормы из памяти** без сверки с белым списком.
2. **Использовать википедию, форумы, неофициальные сайты** для определения действующей редакции.
3. **Игнорировать дату актуальности.** Каждая ссылка на норму — с указанием даты сверки.
4. **Выдавать «общие» формулировки** вместо точного текста статьи.
5. **Имитировать знание** норм, которых не успел проверить.
6. **Использовать ссылки на сторонние ИИ-сервисы** в качестве источника.

### Если поиск в белом списке не дал результата

Сообщи пользователю:
> «На pravo.gov.ru / consultant.ru / garant.ru мне не удалось найти {что искал}. Возможно: (1) такой нормы не существует; (2) норма ведомственная (ДСП); (3) изменена недавно. Уточни у пользователя.»

## 14.09. ПРАКТИЧЕСКИЕ СОВЕТЫ

### 14.09.1. Эффективный поиск пленумов

На vsrf.ru есть раздел «Постановления Пленума ВС РФ» с фильтром по годам и темам. Можно искать по ключевым словам: «о практике рассмотрения», «о применении судами», «о судебной практике».

### 14.09.2. Эффективный поиск судебной практики

На sudact.ru — фильтры по статье УК, типу решения, региону. Используй для проверки, как суд квалифицирует похожие действия по конкретной статье.

### 14.09.3. КонсультантПлюс / Гарант — комментарии

Открытые комментарии к УК / УПК на consultant.ru и garant.ru — полезны для **понимания** нормы (особенно для квалификации сложных составов). Но **не цитируй комментарии в документе** — они не нормативный источник. Цитируй только сам текст нормы.

### 14.09.4. Скоростные проверки

Для быстрой проверки даты последней редакции:
- На pravo.gov.ru ищи строку «Действующая редакция от {дата}».
- На consultant.ru — поле «(в ред. ФЗ от {дата} № {номер})».
