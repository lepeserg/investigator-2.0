Ниже такие места помечены «⚠ РАЗВИЛКА — действующий стиль задаёт персональный слой» с приведением обоих вариантов. Инварианты (общие для всех) даны как норма.

## 2.1. Параметры страницы и шрифт

| Параметр | Значение | Обязательность |
|---|---|---|
| Размер страницы | A4 (21 × 29,7 см) | Обязательно |
| Шрифт | Times New Roman | Обязательно |
| Размер шрифта | 13 pt для основного текста чистого листа; в утверждённом бланке сохранять кегль каждого блока по образцу из формат-профиля | Обязательно с учётом образца |
| Начертание основного текста | обычное (regular) | Обязательно |
| Заголовки (ПОСТАНОВЛЕНИЕ, ПРОТОКОЛ, ХОДАТАЙСТВО, ОБВИНИТЕЛЬНОЕ ЗАКЛЮЧЕНИЕ и т. п.) | жирный (bold), по центру, 13 pt | Обязательно |
| Связки УСТАНОВИЛ: / ПОСТАНОВИЛ: | ⚠ РАЗВИЛКА, см. §2.2 (начертание/разрядка/отбивка — по персональному слою) | Обязательно |
| Межстрочный интервал | 1,0 (одинарный) для основного текста чистого листа; в утверждённом бланке сохранять интервалы блоков по образцу | Обязательно с учётом образца |
| Поля | По персональному слою (не менее минимумов п. 3.1.1 Инструкции: левое ≥ 2,0 см, правое ≥ 1,0 см, верхнее и нижнее по 2,0 см) | Обязательно |
| Абзацный отступ первой строки (красная строка) | 1,25 см в основном тексте; у полей, шапки и подписей утверждённого бланка — геометрия образца | Обязательно с учётом образца |
| Расстояние до колонтитула (верхний и нижний) | 0,5 см от края | Обязательно |
| Выравнивание основного текста | по ширине (ВСЕ документы) | Обязательно |
| Цвет текста | чёрный | Обязательно |

⚠️ **Важно при программной генерации (python-docx):** размер страницы по умолчанию – US Letter (21,59 × 27,94 см), а не A4. Без явной установки `section.page_width = Cm(21.0); section.page_height = Cm(29.7)` документ выйдет нестандартного размера и не совпадёт с реальной бумагой. Скрипт `make_docx.py` это уже делает – оба `build_doc()` и `build_letterhead_doc()`.

> Заголовочные (по центру) и подписные блоки постановлений могут оформляться межстрочным «точно 12 пт» — это корректно (ср. §2.14 про блоки адресата и подписи).

**Утверждённый образец по жанру** — в `references/02a-format-profile.md`. Его внешний вид проверяй
по соответствующим блокам, а не средним кеглем всего файла: бланк протокола может иметь отдельные
служебные надписи и строки подписей с другим шрифтом. Новый текст в основном повествовательном
блоке сохраняет формат этого блока. Для документа, собранного из копии образца, используй режим
`format_lint.py --reference` и визуальный просмотр страниц; проверка «все строки 13 пт» применяется
только к документу на чистом листе без такого образца.

## 2.2. Заголовки документов

### Постановления
Структура заголовка:
```
                ПОСТАНОВЛЕНИЕ                          ← по центру, жирный, 13 pt
о возбуждении уголовного дела и принятии его         ← по центру, обычный, 13 pt
            к производству
```

Слово «ПОСТАНОВЛЕНИЕ» – заглавными буквами, без точек.
Подзаголовок (что за постановление) – строчными буквами в винительном падеже («о возбуждении ...», «о привлечении ...», «об избрании ...», «о признании ...»).

> ★ **РАЗРЯДКА — ✅ ПОДТВЕРЖДЕНО п. 3.2.5 Приказа СК России N 40 (сверено по Гаранту 17.08.2026 по тексту приказа).** Реквизит «Вид документа» печатается **прописными буквами полужирным шрифтом N 14 вразрядку с интервалом „разреженный на 2,5 пт“**. ⚠ **Размер именно 14**, а не 13 — это исключение из общего инварианта TNR 13. ⛔ **На угловых гербовых бланках для писем наименование вида документа НЕ указывается** — на запросах, сопроводах и иных исходящих письмах его нет; указывается на общих гербовых бланках (задания, обзоры, методические рекомендации) и в бланках соответствующего вида документа.

> ⚠ РАЗВИЛКА — оформление связок УСТАНОВИЛ:/ПОСТАНОВИЛ: (действующий стиль задаёт персональный слой; выбор эталона — за человеком после живой сверки п. 3.2.5 и п. 3.6.4.4 Приказа № 40):
> - **Вариант А:** обычный текст (НЕ жирный), ПО ЦЕНТРУ, интервал 6 пт до и после.
> - **Вариант Б:** жирный (bold), по центру.
> - **Вариант В:** прописными, полужирным, вразрядку 2,5 пт; отделяются пустой строкой сверху и снизу с межстрочным интервалом «точно 12 пт» (см. §2.12).

### Протоколы
Структура аналогична:
```
                  ПРОТОКОЛ                          ← по центру, жирный
        допроса обвиняемого                        ← по центру, обычный
```

### Иные документы
- ЗАПРОС / СОПРОВОДИТЕЛЬНОЕ – обычно без специального заголовка, текст начинается с обращения к адресату.
- УВЕДОМЛЕНИЕ – заголовок «УВЕДОМЛЕНИЕ» по центру, жирный.
- ХОДАТАЙСТВО / ПОРУЧЕНИЕ / ПРЕДСТАВЛЕНИЕ – заголовок по центру, жирный.
- ОБВИНИТЕЛЬНОЕ ЗАКЛЮЧЕНИЕ – заголовок «ОБВИНИТЕЛЬНОЕ ЗАКЛЮЧЕНИЕ» по центру, жирный.

## 2.3. Место и дата составления

Стандартный шаблон (под заголовком, после пустой строки):

```
г. {ГОРОД}                                                              {дата по стилю слоя}
                                                                {время по стилю слоя}   ← (опционально, если важно)
```

- Место – в левом краю.
- Дата – в правом краю (через правую табуляцию, не пачкой пробелов).
- Время – на следующей строке справа, если необходимо (для ВУД, протоколов задержания и т. п.).
- **После строки «место / дата (время)» – обязательна ОДНА пустая строка перед основным текстом** (преамбулой). В `make_docx.py` эта пустая строка ставится автоматически блоком `place_date` – отдельный `blank` после него добавлять не нужно.

Альтернативный формат, встречающийся в практике (в постановлениях о выделении/соединении):
```
г. {ГОРОД}   «   20   »   Апреля   20   26   г.
                       (место составления)
```

Используй основной формат (по действующему стилю даты персонального слоя), если нет особых требований.

## 2.4. Дата

> ✅ **СПОСОБ ЗАПИСИ ДАТЫ — ПОДТВЕРЖДЁН п. 3.2.7 Приказа СК России N 40 (сверено по Гаранту 17.08.2026 по тексту приказа).** Дату оформляют **арабскими цифрами**: день месяца и месяц — двумя парами цифр через точку, год — четырьмя цифрами (`01.02.2011`). **Допускается и словесно-цифровой способ**: «1 февраля 2011 г.»; «25 августа 2011 года». ⛔ **В тексте документа НЕ допускается одновременное проставление даты цифровым и словесно-цифровым способами** — смешение прямо запрещено нормой. Действующий стиль отдела задаёт `references/02a-format-profile.md`.
> ⚠ **Приказ разрешает ОБА написания года — и «г.», и «года».** Требование навыка писать только «года» (см. `references/03-style.md`, п. 8) — **домашний стиль владельца, а не требование Приказа N 40**; соблюдать его нужно, но не ссылаться на приказ как на основание.
> **Дата документа** (п. 3.2.7) — дата **подписания** для письма, докладной записки, рапорта, акта; **утверждения или регистрации** — для приказа, распоряжения, инструкции, положения, плана, отчёта; **события** — для протокола заседания. При совместном подписании — дата **более поздней** подписи.

### Вариант А — числовой формат

**ТОЛЬКО формат:** ДД.ММ.ГГГГ

Примеры:
- ✅ 02.05.2026
- ✅ 13.04.2026
- ✅ 21.09.2022

НЕ ПИШИ:
- ❌ 2 мая 2026 года
- ❌ 02.05.26
- ❌ 02/05/2026
- ❌ 02 мая 2026 г.
- ❌ 02-05-2026

### Вариант Б — словесно-цифровой (прописной) формат

Даты пишутся полностью прописью — «ДД месяца ГГГГ года».

Примеры:
- ✅ 12 апреля 2026 года
- ✅ 02 мая 2026 года
- ✅ 21 сентября 2022 года

НЕ ПИШИ:
- ❌ 12.04.2026 (числовой формат)
- ❌ 12.04.26
- ❌ 12/04/2026
- ❌ 12 апреля 2026 г. (без слова «года»)
- ❌ 12-04-2026

#### 2.4.1. Даты нормативных правовых актов — ТОЖЕ прописью (применяется в варианте Б)

Чтобы не было смешения форматов в одном документе (запрет п. 3.2.7 Приказа № 40), при прописном стиле даты в ссылках на НПА (указы, законы, приказы, постановления Пленума) пишутся **прописью наравне с основным текстом**.

- ✅ Указ Президента Российской Федерации от 21 сентября 2022 года № 647
- ✅ Федеральный закон от 28 марта 1998 года № 53-ФЗ «О воинской обязанности и военной службе»
- ✅ Дисциплинарный устав …, утверждённый Указом Президента Российской Федерации от 10 ноября 2007 года № 1495
- ✅ Постановление Пленума Верховного Суда Российской Федерации от 18 мая 2023 года № 11

НЕ ПИШИ:
- ❌ Указ … от 21.09.2022 № 647 (цифровая дата НПА при прописных датах в тексте — смешение форматов)
- ❌ Федеральный закон от 28.03.1998 № 53-ФЗ

> Номер НПА (№ 647, № 53-ФЗ) при этом остаётся цифрами — прописью пишется только **дата**.

**При вычитке документов, оформленных по этому стандарту, прозаический формат даты НЕ исправлять** — общий стандарт по всем жанрам. Наоборот: цифровые даты НПА в чужих черновиках приводить к прописному формату.

**Исключение (для обоих вариантов):** в гербовых грифах «УТВЕРЖДАЮ» и «СОГЛАСЕН» дата может оставляться пустой для подписи руководителя/прокурора («___» _________ 20__ г.).

## 2.5. Время

> ⚠ РАЗВИЛКА — способ записи времени (связан со стилем даты §2.4; действующий стиль задаёт персональный слой).

### Вариант А — сокращённый формат

**ТОЛЬКО формат:** ЧЧ ч. ММ мин.

Примеры:
- ✅ 14 ч. 30 мин.
- ✅ 09 ч. 05 мин.
- ✅ 11 ч. 46 мин.
- ✅ 00 ч. 00 мин.

НЕ ПИШИ:
- ❌ 14:30
- ❌ 14.30
- ❌ 14 час. 30 мин.
- ❌ 14ч30мин
- ❌ в 14 часов 30 минут

### Вариант Б — прописной формат

Время пишется полностью прописью — «ЧЧ часов ММ минут».

Примеры:
- ✅ 14 часов 30 минут
- ✅ 09 часов 05 минут
- ✅ 11 часов 46 минут
- ✅ 00 часов 00 минут

НЕ ПИШИ:
- ❌ 14:30
- ❌ 14.30

**Используется:** для протоколов следственных действий (начало/окончание), для постановлений о возбуждении дела при срочности, для уведомлений о задержании.

## 2.6. Денежные суммы

**Формат:** {сумма_цифрами} руб. {копейки} коп.

С разрядными пробелами в больших числах.

Примеры:
- ✅ 15 000 руб. 00 коп.
- ✅ 750 000 руб. 00 коп.
- ✅ 1 250 руб. 50 коп.
- ✅ 5 руб. 00 коп.

В резолютивной части или ОЗ – с числом прописью (для крупных сумм):
- ✅ 750 000 (семьсот пятьдесят тысяч) руб. 00 коп.

НЕ ПИШИ:
- ❌ 15000 руб. (без пробела)
- ❌ 15.000 руб. (точка как разделитель)
- ❌ 15 000 рублей
- ❌ $15 000
- ❌ 15000,00 руб.

## 2.7. Числа и числительные

**Числа** – арабскими цифрами, **без падежных окончаний и порядковых суффиксов**.

Примеры:
- ✅ 3 роты
- ✅ 7 дивизия
- ✅ {ОРГАН_ПОЛН}
- ✅ в воинской должности водителя 3 отделения

НЕ ПИШИ:
- ❌ 3-й роты
- ❌ 3-я рота
- ❌ 7-я дивизия
- ❌ третьей роты
- ❌ седьмой дивизии

**Исключение для номеров статей и пунктов:**
- ✅ ч. 5 ст. 337 УК РФ
- ✅ п. «б» ч. 4 ст. 291 УК РФ
- ✅ п. 1 ч. 1 ст. 24 УПК РФ

(Здесь нумерация – это часть нормативной структуры, без падежных окончаний цифры.)

## 2.8. Воинские части

**Формат:** «в/часть {номер}» – БЕЗ знака «№». (Номера частей ниже — условные, пример.)

Примеры:
- ✅ в/часть 00000
- ✅ войсковая часть 00000

НЕ ПИШИ:
- ❌ в/часть № 00000
- ❌ В/Ч 00000
- ❌ часть 00000

Форма «в/ч 00000» допустима, но менее предпочтительна, чем «в/часть 00000».

**Особый формат для частей в зоне СВО (полевая почта):**
- ✅ в/часть – полевая почта 00000
- ✅ войсковая часть – полевая почта 00000
- ✅ в/части п.п. 00000 (в текстах допроса при упоминании места службы)

## 2.9. Тире

**ТОЛЬКО короткое тире:** **–** (en dash, U+2013)

Длинное тире (— em dash, U+2014) – **запрещено вообще никогда: ни в одном документе, ни в одном ответе**. Везде, где нужно тире, ставь только короткое (–).
Дефис (- hyphen-minus) на месте тире – **запрещён**.

> **Автоконтроль (страховка генератора):**
> `make_docx.py` сам заменяет «—», «―» и «--» на «–» в любом тексте абзаца
> (функция `_normalize_dashes`, вызывается в `_add_para`). Но это страховка только для
> генератора. В **чате**, при правках через `docx_edit.py` и при вычитке набирай короткое
> «–» сразу — на эти пути автозамена не распространяется.

Примеры:
- ✅ Преступление, предусмотренное ч. 5 ст. 337 УК РФ – самовольное оставление части в период мобилизации.
- ✅ Заведомо подложная медицинская справка – документ, выданный ...
- ✅ войсковая часть – полевая почта 00000

НЕ ПИШИ:
- ❌ ... ч. 5 ст. 337 УК РФ — самовольное оставление... (длинное тире — запрещено)
- ❌ ... ч. 5 ст. 337 УК РФ - самовольное оставление... (дефис вместо тире)

**Дефис допустим только в составных словах:** «военно-врачебная комиссия», «оперативно-розыскные мероприятия», «гарнизонный военный суд» (без дефиса), «беспрепятственно», «военно-следственные».

## 2.10. Кавычки

**Основные кавычки – ёлочки:** **«»**

Внутри ёлочек, если нужна вложенность – лапки: **„“**

Примеры:
- ✅ Постановление Пленума ВС РФ от 18.05.2023 № 11 «О практике рассмотрения судами уголовных дел о преступлениях против военной службы»
- ✅ Согласно приказу командира в/части 00000 «О зачислении в списки личного состава» ...
- ✅ Свидетель пояснил: «Я видел, как он сел в машину „Лада“.»

НЕ ПИШИ:
- ❌ "О практике рассмотрения..." (английские кавычки)
- ❌ ''О практике...'' (одинарные)
- ❌ «О практике рассмотрения «дел о преступлениях...» (двойные ёлочки внутри)

## 2.11. Сокращения – стандартные и обязательные

> ⚙ **Механическая проверка:** `scripts/style_lint.py`, флаг **`норма-словом`** — ловит
> нормативную ссылку, развёрнутую словом («пунктом 1.3 статьи 7»). ⚠ Дословно процитированный
> заголовок статьи и номер войсковой части флагом не считаются. Замер по корпусу: 10 %
> документов, 279 попаданий — правило нарушалось и в старых документах.

> Наименование и аббревиатура надзирающей военной прокуратуры — константа персонального слоя (`{ПРОКУРАТУРА_НАДЗ}`), в общую таблицу не выносится.

## 2.14. Структура запроса / сопровода – обязательные блоки

```
1. ШАПКА: УГЛОВИК (слева) + АДРЕСАТ (справа)
                                          {Должность, ФИО получателя}

2. ОТСТУП ОТ ШАПКИ ДО ОСНОВНОГО ТЕКСТА – 4 ПУСТЫЕ СТРОКИ

3. ОБРАЩЕНИЕ (если уместно – для сопроводов прокурору, в суд, писем руководителям) – ПО ЦЕНТРУ, обычным начертанием
                        Уважаемый {Имя Отчество}!

4. ОСНОВНОЙ ТЕКСТ
   {Обоснование, перечень требуемого, ссылки на нормы.}

5. ПЕРЕЧЕНЬ ПУНКТОВ (для запросов с перечнем)
       1. ... .
       2. ... .
       ...

6. ССЫЛКА НА НОРМЫ И ПРОСИТЕЛЬНАЯ ЧАСТЬ
   В связи с изложенным и руководствуясь {нормы}, прошу {что}
   {куда направить}.

7. КОНТАКТНЫЕ ДАННЫЕ
   Наш адрес: {АДРЕС_ОРГАНА}. Электронный адрес: {EMAIL_ОРГАНА}.

8. ДВЕ ПУСТЫЕ СТРОКИ

9. ПОДПИСНОЙ БЛОК
```

> Пункты нумерованного перечня оканчиваются точкой (см. §2.15, ⚠ развилка «точка с запятой»).

**Уточнения по шапке и обращению (обязательно):**
- Обращение «Уважаемый {Имя Отчество}!» размещается **по центру**, обычным (не жирным) начертанием, на отдельной строке.
- Между верхней шапкой (угловик + адресат) и основным текстом (обращением) – **4 пустые строки**.
- Угловой штамп (бланк) вставляется **без рамок** – чистое изображение, обрезанное по содержимому.
- Основной текст выравнивается **по ширине**.
- Отступ первой строки **везде 1,25 см**, включая пункты нумерованного перечня (номер пункта стоит в первой строке абзаца, перенос – к левому полю).
- Межстрочный интервал текста **адресата** и **подписного блока (должности)** – **точно 12 пт** (рывок «Точно 12 пт»), включая пустые строки внутри этих блоков.
- Между основным текстом и подписным блоком (должностью) – **2 пустые строки с интервалом точно 12 пт**.
- **Висячих подписей быть не должно:** подписной блок (должность + Ф.И.О.) не должен оставаться один на новой странице в отрыве от текста. В `make_docx.py` весь блок `signature` собран с `keep_together`/`keep_with_next`. Если документ всё же не помещается на одну страницу – допустимо аккуратно расширить верхнее/нижнее поле; **если аккуратно подогнать не получается – спросить у пользователя, как лучше сделать** (а не оставлять висящую подпись).
- **В подписном блоке фамилия с инициалами подписанта прижимается к ПРАВОМУ краю** строки (через правую табуляцию на ширину рабочего поля), должность/звание – слева. В `make_docx.py` это делает блок `signature` автоматически (строка «звание\tФ.И.О.» с правым табулятором).
- **Висячие предлоги.** Неразрывный пробел (U+00A0) НЕ используем – генератор его не вставляет (`_apply_nbsp` отключён). Если при вычитке короткий предлог/союз остался в конце строки, следователь убирает его **вручную комбинацией Shift+Enter** (мягкий перенос перед предлогом, чтобы тот ушёл на следующую строку вместе со своим словом). Символ U+00A0 в текст документов не добавляем.

## 2.15. Перечни и нумерация

### Нумерованные пункты в постановляющей части или перечнях
- Используй арабские цифры с точкой: `1.`, `2.`, `3.`
- После цифры – пробел и текст пункта.
- **Каждый нумерованный пункт – это отдельный абзац с «красной строкой» (абзацный отступ первой строки 1,25 см), как и весь основной текст** (номер пункта стоит в первой строке абзаца на отступе 1,25 см, перенос строк – к левому полю). В `make_docx.py` для этого используется блок `{"type": "li", ...}` (отступ 1,25 см + выравнивание по ширине). **НЕ использовать `para_no_indent` для нумерованных пунктов** – он даёт нулевой отступ (без красной строки). Это правило действует для резолютивных частей ВСЕХ постановлений и нумерованных перечней во всех жанрах.
- **С КРАСНОЙ СТРОКИ – ВСЕ строки «Вопрос следователя:» и «Ответ:» в объяснениях/протоколах допроса, а также пункты в перечнях прав** (ч. 4 ст. 46/47/56, ст. 42 УПК РФ, ч. 1.1 ст. 144 и т. п.). И вопросы/ответы, и пункты прав начинаются с красной строки (абз. отступ 1,25 см), а не флешем к левому полю. В `make_docx.py` использовать `{"type":"li"}` (или блок с красной строкой), НЕ `para_no_indent`, для: каждой строки «Вопрос следователя: …», каждой строки «Ответ:», каждого пункта прав. Преамбулу-связку («Перед получением объяснения… разъяснены права…») оставлять обычным абзацем с красной строкой.
- **Не заканчивай пункты точкой с запятой (;).** Каждый пункт – отдельное предложение, оканчивается точкой. Точку с запятой по возможности не используем нигде (исключение – дословная цитата нормы закона). *(⚠ развилка: правило явно закреплено не во всех отделах — подтвердить у владельцев персональных слоёв; шаблоны-скелеты со «;» привести к точке.)*

### Маркированные списки
- В постановлениях, протоколах и запросах **избегай маркеров (●, –, *)**.
- Если нужно перечисление без нумерации (например, в перечне доказательств) – используй короткое тире (–) в начале строки:
  ```
  – {Первый элемент}.
  – {Второй элемент}.
  – {Третий элемент}.
  ```
- В описательной части (фабула) – **никаких** списков, только сплошной текст с обозначением последовательности через слова «затем», «после чего», «также».

## 2.18. Колонтитулы

В постановлениях и протоколах **колонтитулы не используются**, кроме двух случаев: номер уголовного дела в колонтитуле ВУД (§2.22) и **нумерация страниц** (§2.24).

⛔ **Нумерация страниц описана ТОЛЬКО в §2.24** — верхний колонтитул, по центру, Times New Roman 13, кроме первой страницы, при длине документа больше двух страниц. Прежняя развилка «внизу справа со 2-й страницы» закрыта требованием владельца 19.08.2026; вариант «внизу справа» больше не применяется.

## 2.19. Форматы носителя (чистый лист / бланк)

**На чистом листе (без бланка) – ВСЕГДА** оформляются процессуальные решения и фиксация:
- постановления (ВУД, ОВУД, обвинение, мера пресечения, экспертиза, прекращение и т.д.).
- протоколы (допросов, осмотров, выемки, обыска, ППМ, опознания, ст. 217).
- обвинительное заключение.
- ходатайства в гарнизонный военный суд (ст. 165, 108, 109, 115 УПК РФ).

Программно – функция `build_doc()`.

**Процессуальная переписка** (запросы в в/часть, банк, военкомат, медорганизацию, ИЦ/ГИАЦ, ФНС, Росреестр, ГИБДД, ЗАГС, оператора связи, ОВД; сопроводительные письма прокурору, в суд, командиру в/части; повестки ст. 188; справки; уведомления ст. 215, 223.1, о приостановлении/возобновлении/прекращении; поручения о производстве отдельных СД ст. 152; представления об устранении обстоятельств ч. 2 ст. 158) – оформляется по **модели бланка, заданной персональным слоем**:
- **(а) типографский / файловый бланк** – реквизиты и герб в шапке; программно `build_letterhead_doc()`, файл бланка передаётся из персонального слоя. Геометрия шапки (уровень адресата, `ADDRESSEE_DROP_LINES`, `LETTERHEAD_LEADING_LINES`, отступ адресата) – параметры персонального слоя.
- **(б) угловой бланк-изображение** – угловой штамп вставляется картинкой (ширина, снятие рамки, `addressee_offset_lines` – значения из персонального слоя).
- **(в) без бланка** – переписка на чистом листе; если нужен конкретный бланк, пользователь предоставляет файл-шаблон.

**Контрольная проверка перед выдачей** – какой документ генерируется и подходящая ли функция вызвана. Для органов с бланком: **постановление на бланке с гербом – ошибка; запрос без бланка – тоже ошибка.**

**Дополнения по оформлению (инварианты):**
- Формат страницы – **A4 (210 × 297 мм)**; генератор выставляет A4 принудительно.
- **Подпись:** фамилия подписанта прижата к правому полю **правой табуляцией** до границы рабочего поля (а не пачкой табов).
- **Несколько адресатов** – в одном письме блоком, короткими строками (длинные наименования разбивать: «УФСИН России» / «по … области»), между адресатами – пустая строка.

## 2.20. Анкетные данные (анкета) – ЕДИНЫЙ СТАНДАРТ

> ⚠️ **ДЕЙСТВУЕТ ВО ВСЕХ ЖАНРАХ, ГДЕ ЕСТЬ АНКЕТА ЛИЦА** – протокол допроса (свидетеля/потерпевшего/подозреваемого/обвиняемого), протокол объяснения, раздел «ОБВИНЯЕТСЯ …» обвинительного заключения. Единая раскладка – чтобы анкета выглядела одинаково везде.

**Анкета оформляется скрытой (безрамочной) таблицей 2×N:**
- **Таблица без границ** (все линии скрыты) – визуально это две колонки: слева пункт с номером, справа значение.
- **Колонки:** левая – **6,5 см** (текст пункта: «1. Фамилия, имя, отчество», «2. Дата рождения» …), правая – **10,0 см** (значение).
- **Выравнивание – по ЛЕВОМУ краю** в обеих колонках (НЕ по ширине, НЕ по правому). Шрифт TNR 13, межстрочный одинарный.
- **Интервал между строками** задаётся `space_after = 4 пт` для всех строк, кроме последней (у последней – 0). Пустыми абзацами интервал НЕ набивать.
- **Хвостовые «;» и «.»** в конце значений не ставить (движок срезает).
- **Пробелы – только обычные. НИКОГДА не вставлять неразрывные пробелы (nbsp)**, ни в анкете, ни в тексте. Висячий предлог/короткое слово в конце строки, если реально мешает, убирать **вручную мягким переносом (Shift+Enter)** перед этим словом – а не nbsp.

**В `make_docx.py`** – блок `{"type": "anketa", "items": [["1. Фамилия, имя, отчество", "Ф.И.О."], ["2. Дата рождения", "{дата по стилю слоя}"], …]}`. Вся раскладка (скрытая таблица, колонки 6,5/10,0, левое выравнивание, `space_after=4`, срез хвостов) **уже зашита в блок – вручную ничего настраивать не нужно**, просто передавать пары «пункт → значение». Неразрывные пробелы блок НЕ вставляет (обычные пробелы).

**Числа в анкете:** дата рождения – **день двумя цифрами** («02 января 1975 года», НЕ «2 января»); в остальном по §2.4/2.7.

## 2.21. Буква «ё»

В тексте документов используется «е», а не «ё»: «наделен», «Вооруженных Силах», «заключен», «определенные», «неопределенного», «совершенном», «объем», «с учетом». Исключение – если иное написание меняет смысл (имена собственные при необходимости). При программной генерации выполнять финальную замену ё→е, Ё→Е по всему тексту. *(⚠ развилка: правило явно закреплено не во всех отделах — подтвердить у владельцев персональных слоёв.)*

## 2.22. Номер уголовного дела в колонтитуле ВУД

В постановлении о возбуждении уголовного дела номер дела ставится в ВЕРХНЕМ колонтитуле ПЕРВОЙ страницы, по ПРАВОМУ краю: «№ {маска номера дела органа — код органа из персонального слоя `{КОД_ОРГАНА_УД}`}» (Times New Roman 13, обычный). На остальных страницах и в других документах (рапорт, выделение, сопровод) такого колонтитула нет. Программно – функция `add_case_header(path, number)` в `make_docx.py` (применяется после сборки ВУД).

## 2.23. Личный номер военнослужащего

Личный номер военнослужащего указывается только в анкетных реквизитах и запросах, где он необходим, — в своём поле; в описательной части (фабуле) его нет (`03-style-chek-list-zakreplennye.md` §3.17 п. 3, `17-verification-checklist-zhanry.md` §17.2).

## 2.24. Нумерация страниц (требование владельца 19.08.2026)

| Параметр | Значение |
|---|---|
| Где | **верхний колонтитул** |
| Выравнивание | **по центру** |
| Шрифт | **Times New Roman 13** |
| Первая страница | **без номера** |
| Когда ставится | документ **длиннее двух страниц** (3 и более) |

⛔ **Первая страница исключается механизмом Word «особый колонтитул для первой страницы»**, а не
пустой строкой и не ручным удалением номера. ⚠ Если у документа уже есть верхний колонтитул
(например, № уголовного дела), его содержимое **сначала переносится в колонтитул первой страницы** —
иначе включение режима сотрёт шапку с первого листа.

**Как ставить:**

```bash
python scripts/docx_edit.py "файл.docx" --page-numbers
```

Инструмент сам считает страницы (Word в **своём** процессе — правило 39; если Word недоступен, берёт
`docProps/app.xml`) и при двух и менее страницах **ничего не делает**, о чём сообщает. Число страниц
не определилось — посчитать рендером и запустить с `--force`.

⚠ **Двухстраничный документ нумерации не получает** — это не недоработка, а требование: на двух
листах номера не нужны.

## 2.25. Телефонные номера

В документ и карточку дела вносятся только проверенные номера телефонов, сверенные между документами (§16.08.3); в банковской части номер телефона — идентификатор получателя в СБП, а не счёт (§18.12.2).
