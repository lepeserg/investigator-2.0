## 09.19. ЗАПОЛНЕНИЕ docx-БЛАНКОВ ЧЕРЕЗ ПОЛЯ ФОРМЫ (Word COM) — ОСНОВНОЙ ПУТЬ НА WINDOWS ★★

> ⚠ Путь для **вордовских** бланков. Excel-формы ГВП заполняются иначе — §09.18;
> ⛔ правило 43 (даты строкой) действует в обоих путях.

> ⓘ Не жанр — техника заполнения через поля формы Word. Карточка жанра не требуется.

### 09.19.1. Бланки статкарт — это ФОРМЫ Word, а не просто таблицы

Мы годами писали в них координатами ячеек через python-docx и боролись со шрифтом. Замер бланков:

| Бланк | Полей формы | из них списков | Защита |
|---|---|---|---|
| **Ф-1** (файл `Ф-1 (ЧИСТЫЙ бланк).docx`) | **96** | 38 | `w:documentProtection w:edit="forms"` |
| **Ф-1.2** (файл `Ф-1.2 (ЧИСТЫЙ бланк).docx`) | 86 | — | та же |
| **Ф-1.1** (файл `Ф-11 нов.docx`) | 189 | — | та же |
| **Ф-1 + Ф-1.2** — пакет (файл `Ф-12 нов.docx`) | 97 (58 + 39) | — | та же |
| **Ф-5 / Ф-2 / Ф-3 / Ф-1.3** (файлы `Ф-5 нов` / `Ф-2 нов` / `Ф-3 нов` / `Ф-13 нов`) | 85 / 43 / 36 / 28 | — | та же |

⚠ **Замер 06.08.2026 сделан на легаси-файлах — с 26.08.2026 они в архиве `Старые стат. карты\`.**
Вывод «бланки статкарт — формы Word» держится и на рабочих бланках подпапки, полей там БОЛЬШЕ:
Ф-1 101 · Ф-1.1 210 · Ф-1.2 94 · Ф-1.3 90 · Ф-2 69 · Ф-3 36 · Ф-5 86 · Ф-6.1 333 (§09.09).
⛔ **В таблице — НАЗВАНИЯ ФОРМ, в скобках имена файлов** (карта соответствия — §09.09).
⛔ **Число полей формы ≠ покрытие граф:** у Ф-1.1 полей 189, а номер графы определился у **8**
из них — см. §09.19.5.

Что это даёт — и почему это лучше координат:

1. ⭐ **«Ловушка Times New Roman» (§09.15) исчезает В КОРНЕ.** Word сам применяет формат поля.
   Не нужны ни `set_statcard_cell`, ни `font_from`, ни последующий `fix_statcard_font`.
2. ⭐ **Коды нельзя выдумать.** Выпадающие списки несут САМ ПЕРЕЧЕНЬ кодов графы —
   например графа 2.4: `01, 02, 11, 12, 10, 61, 63, 65, 67, 69, 21, 22, 25, 20, 32, 35, 41, 40,
   51, 50, 71, 72, 80, 90`. Это снимает целый класс возвратов (ср. §09.12.2 и историю с кодом 41).
4. **Адресация не «съезжает».** Поле адресуется индексом, а не `[таблица][строка][столбец]`,
   поэтому сдвиг вёрстки бланка карту не ломает — в отличие от CELLMAP (§09.16).
5. **Подписной блок тоже списочный:** графа 2.19 — должность (`След-ль, Ст.след., След-крим.,
   Ст.след-крим, След.ОВД…`) и звание (`Л-т юст., Ст.л-т юст., К-н юст., М-р юст., П/п-к юст.,
   П-к юст.`) выбираются из перечня; значения из `константы.json` подставлять В ФОРМУЛИРОВКЕ СПИСКА.

⛔ **python-docx полей формы НЕ понимает** — он видит только текст-результат. Поэтому координатный
путь §09.16 остаётся ЗАПАСНЫМ: он нужен там, где нет Word, то есть в Cowork.

### 09.19.2. Как заполнять

Скрипт **отказывается** записать значение вне перечня списка и печатает допустимые коды;
отказывается адресоваться по графе, если под ней несколько полей (для Ф-1 графа 2.12 — это
12 полей), и называет их номера. Оба отказа — без создания файла.

### 09.19.3. Грабли (все воспроизведены)

Ограничения пути через поля формы — §09.19.1–09.19.2; число страниц и параметры печати по эталону — §09.18.10 и §09.18.13; сводка граблей COM — §09.18.15.

### 09.19.4. Какой путь для какой формы

| Форма | Путь | Почему |
|---|---|---|
| **Ф-1, Ф-1.2** | **Excel ГВП** (§09.18), когда прокурор их принимает | только там СКВОЗНАЯ логика (40 правил), справочник статей с периодами действия и блокировка выгрузки при ошибках |
| **Ф-1.1, Ф-2, Ф-3** | **`docx_edit` + `set_statcard_cell` по координатам** (§09.16); Word COM — только под выпадающие списки | ⛔ значащие графы этих форм полями формы НЕ являются — §09.19.5 |
| **Ф-1.3, Ф-5, Ф-6** | **Word COM по полям формы** (этот раздел) | в комплекте ГВП этих форм НЕТ, а поля формы дают шрифт, коды и типы. ⚠ покрытие граф на них не перепроверялось — снять `inventory` и посмотреть, как в §09.19.5 |
| любая, в Cowork | `docx_edit` по координатам (§09.16) | нет ни Word, ни Excel |

⛔ **Имена форм, а не файлов.** Бланк под форму — по карте §09.09 (`Ф-11.docx` = Ф-1.1,
`Ф-13.docx` = Ф-1.3; архивный `Ф-12 нов` = пакет Ф-1 + Ф-1.2).

⛔ Не заявлять «карточка проверена» ни в одном из путей: в Excel гейт — «Ошибок: 0» на панели,
в Word-пути — `verify` плюс глаза владельца. `fill_formfields` проверяет ФОРМУ значения
(перечень, тип, длина), но не смысл: правильность самого кода по фабуле — на ассистенте (§09.17).

### 09.19.5. ⛔ НА Ф-1.1, Ф-2 И Ф-3 ЗНАЧАЩИЕ ГРАФЫ — НЕ ПОЛЯ ФОРМЫ ★★

**1.1** № дела · **1.2** дата · **2.1.а** код решения · **2.3.а-б** состав · **3.2.а / 3.2.б**
подписанты.

Причина: `inventory` берёт номер графы из крайних ячеек строки таблицы, а на этих бланках строка
объединена и крайняя ячейка пуста.

⛔ **Отсюда маршрут для Ф-1.1, Ф-2, Ф-3 — СМЕШАННЫЙ, и «Word COM по полям формы» его основным
путём НЕ является:**

| Что заполняем | Чем |
|---|---|
| текстовые графы (№ дела, даты, состав, ФИО, подписанты) | **`docx_edit.edit_file`** (run-aware правка) |
| графа с кодом решения (2.19.а Ф-2, 2.1.а Ф-1.1, 2.1 Ф-3) | **`set_statcard_cell`** по координате |
| выпадающие списки (должность и звание в 3.2/3.3, орган «01») | **Word COM** (`fill_formfields.py`) либо простановка владельцем в Word |

⛔ Следствия, которые надо помнить именно на этом пути:
- «ловушка Times New Roman» тут **возвращается** (поля формы её больше не снимают) — писать через
  `{"op":"cell", ..., "statcard":True, "font_from":[r,c]}` и прогонять `scripts/fix_statcard_font.py` (§09.15);
- ⛔ `replace_all` по званиям, должностям и фамилиям **запрещён** — §09.00.1;
- координаты снимать `make_statcards.py grid` со своего бланка, не по памяти (§09.00 п. 2).

⚠ Если `inventory` на Ф-1.1/Ф-2/Ф-3 когда-нибудь начнёт определять графы (определение графы в
`scripts/fill_formfields.py` починено) — маршрут пересмотреть, но **не раньше**, чем замер покажет
покрытие ключевых граф из списка выше.

## 09.20. ⛔ НЕТ ДАННЫХ О ЛИЧНОСТИ — СТАВИТЬ НАИБОЛЕЕ ВЕРОЯТНОЕ, А НЕ ПУСТО И НЕ ВОПРОС ★★

> ⓘ Не жанр — правило заполнения граф личности при отсутствии данных. Карточка жанра не требуется.

**Анкетных данных о личности на этапе возбуждения дела не бывает** — ни образования, ни того, кем
воспитывался, ни социального положения. Это статистические графы, а не предмет доказывания;
следствие их устанавливает позже, а карта сдаётся сразу. Поэтому:

⛔ **Не спрашивать владельца про эти графы и не оставлять их пустыми.** Ставить **наиболее
вероятное** значение по роду занятий и возрасту фигуранта. Формы ГВП вдобавок **блокируют выгрузку**
при пустом социальном положении (это «Ошибка», а не предупреждение) — пустая графа просто не даст
выпустить карту.

Умолчания (Ф-1.2, коды по перечням самой формы):

| Графа | Умолчание | Когда иначе |
|---|---|---|
| **2.6 Кем воспитывался** | **1 — двумя родителями** | есть данные об ином |
| **2.9 Образование** | **3 — среднее (полное) общее** | «серьёзный человек» (офицер, должностное лицо, руководитель, специалист) → **1 — высшее профессиональное**; из первоисточника «среднее специальное» → **2** |
| **2.7.а Семейное положение** | по материалам; при отсутствии — **2 (женат)** для лиц старше 30 лет | явные данные об ином |
| **2.12 Социальное положение** | наиболее вероятное по роду занятий: наёмный рабочий (12), служащий (13), пенсионер по старости (31), безработный (35); военнослужащий по контракту (01) / по призыву (02) — по статусу | есть первоисточник |
| **2.13 Должностное положение** | прочерк для гражданских лиц | должностное лицо — по фактической должности |

⚠ **Это НЕ отменяет правило 28** (персональные данные из первоисточника): ФИО, дата и место
рождения, адрес, звание, должность, личный номер, реквизиты документов — **только из материалов**,
их предполагать нельзя. Умолчания выше касаются **исключительно статистических граф о личности**,
которых на стадии возбуждения объективно нет ни у кого.

⚠ Умолчание, поставленное «по вероятности», **не переносится в процессуальные документы**
(ВУД, обвинение, ОЗ, протоколы) — там пробел закрывается по правилу 23 и правилу 30.
