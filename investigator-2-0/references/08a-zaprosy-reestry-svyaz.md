## 08.06. ЗАПРОС В ФНС

### ● Карточка жанра

**Маршрут.** Бланк органа с угловым штампом, адресат блоком справа; структура — эталон §08.00.3. Донор обязателен (правило 12), таблиц — **0**. Общие требования переписки — `references/08d-peredacha-obshchie.md` §08.20. ⛔ **ФНС — оператор ФИС ЕГР ЗАГС** (ст. 13.1 ФЗ № 143-ФЗ); сами записи актов вносят органы ЗАГС, поэтому не путать адресата с §08.08. Адресация — `references/08f-adresaciya-zaprosov.md`, реквизиты — `адресаты.json`.

**Комплект.** Обычно — сведения о доходах, участии в юридических лицах, регистрации ИП. По подставным лицам в ЕГРЮЛ смыкается с составами ст. 173.1, 173.2 УК.

**⛔ Фатальные ошибки.** Реквизиты адресата выдуманы вместо поиска в открытых источниках (§08.20.8) · **чужая регистрация (№ КУСП, ОМВД) в преамбуле** — правило 25 · подписант взят из донора вместо матрицы (правило 2) · персональные данные фигуранта перенесены из донора (правило 28) · не указан почтовый адрес ВСУ для ответа (§08.00.3 п. 6).

**Гейт.** Адресат и по какому правилу он выбран (фиксированный / по месту жительства / по месту службы) · источник реквизитов · подписант · дата живой сверки формулы основания · **хвост по §08.30** стоит (три абзаца дословно + «Наш адрес»), донорских «В связи с изложенным и руководствуясь ст. 21, 38, 39 УПК… прошу направить…» и «Срок исполнения: до …» нет.

### 08.06.1. Применение

Для получения сведений о доходах, имуществе, регистрации индивидуальной предпринимательской деятельности, юридическом лице.

### 08.06.2. Шаблон (краткий)

Адресат: «Начальнику Управления ФНС России по {субъекту РФ}».

Перечень:
1. Сведения о доходах {Ф.И.О.} за период с __ по __ (форма 2-НДФЛ).
2. Сведения о наличии регистрации в качестве индивидуального предпринимателя.
3. Сведения о принадлежности доли в уставном капитале организаций.
4. Сведения о наличии задолженности по налогам.
5. Иные сведения, имеющиеся в налоговом органе.

Структура шаблона аналогична 08.05.

## 08.08. ЗАПРОС В ЗАГС

### ● Карточка жанра

**Маршрут.** Бланк органа с угловым штампом, адресат блоком справа; структура — эталон §08.00.3. Донор обязателен (правило 12), таблиц — **0**. Общие требования переписки — `references/08d-peredacha-obshchie.md` §08.20. ⛔ **ЕГР ЗАГС — ФЕДЕРАЛЬНЫЙ реестр с 01.10.2018**: менять адресата по региону составления акта **НЕВЕРНО** (§08f.01, §16.29). Адресат фиксированный либо по правилу персонального слоя. Адресация — `references/08f-adresaciya-zaprosov.md`, реквизиты — `адресаты.json`.

**Комплект.** Входит в пакет после ВУД. Запрашиваются сведения о рождении, заключении и расторжении брака, смерти, перемене имени — для анкеты обвиняемого и установления родственных связей.

**⛔ Фатальные ошибки.** Адресат выбран «по месту составления акта» · перепутан с ФНС как оператором реестра (§08.06) · Реквизиты адресата выдуманы вместо поиска в открытых источниках (§08.20.8) · **чужая регистрация (№ КУСП, ОМВД) в преамбуле** — правило 25 · подписант взят из донора вместо матрицы (правило 2) · персональные данные фигуранта перенесены из донора (правило 28) · не указан почтовый адрес ВСУ для ответа (§08.00.3 п. 6).

**Гейт.** Адресат и по какому правилу он выбран (фиксированный / по месту жительства / по месту службы) · источник реквизитов · подписант · дата живой сверки формулы основания · **хвост по §08.30** стоит (три абзаца дословно + «Наш адрес»), донорских «В связи с изложенным и руководствуясь ст. 21, 38, 39 УПК… прошу направить…» и «Срок исполнения: до …» нет.

### 08.08.1. Применение

Для получения сведений о записях актов гражданского состояния (рождение, брак, развод, смерть).

### 08.08.2. Адресат — ФИКСИРОВАННЫЙ, вариантов нет

⛔ **Разночтение снято 30.07.2026** (прежняя редакция допускала «вариант А — по месту регистрации
акта»; это неверно и уже привело к ошибке в боевом пакете).

**ЕГР ЗАГС — единый ФЕДЕРАЛЬНЫЙ реестр (ведётся с 01.10.2018)**, поэтому сведения выдаёт любой орган
ЗАГС независимо от того, в каком регионе составлена запись акта. Адресат берётся из
`адресаты.json` → `фиксированные_независимо_от_региона_фигуранта.ЗАГС`; менять его «по логике места
регистрации акта» **запрещено** (§08f.01, §16.29).

Реальный индикатор из корпуса: у фигуранта-уроженца другого региона рядом лежат «ЗАГС Казань» и
«военкомат/диспансеры» его региона — то есть ЗАГС фиксирован, а медицина и военкомат по региону.

### 08.08.3. Перечень

1. Копия записи акта о рождении {Ф.И.О.} (для подтверждения родственных связей).
2. Копия записи акта о заключении брака.
3. Копия записи акта о расторжении брака.
4. Копия записи акта о смерти (при наличии).

## 08.10. ЗАПРОС В ОПЕРАТОРА СВЯЗИ

### ● Карточка жанра

**Маршрут.** Бланк органа с угловым штампом, адресат блоком справа; структура — эталон §08.00.3. Донор обязателен (правило 12), таблиц — **0**. Общие требования переписки — `references/08d-peredacha-obshchie.md` §08.20. ⛔ **Разграничение:** абонентские и учётные данные запрашиваются письмом, а **сведения о СОЕДИНЕНИЯХ между абонентами — только по судебному решению ст. 186.1 УПК** (`references/07d-mery-presecheniya.md` §07.13.7); контроль и запись переговоров — ст. 186, §07.13.6. Адресация — `references/08f-adresaciya-zaprosov.md`, реквизиты — `адресаты.json`.

**Комплект.** Запрос учётных данных · при необходимости соединений — ходатайство в суд, сопровод в гарнизонный военный суд, затем осмотр полученных сведений и признание вещдоком.

**⛔ Фатальные ошибки.** ⛔ Через обычный запрос получены сведения о соединениях — доказательство недопустимо · не индивидуализирован абонентский номер и период · Реквизиты адресата выдуманы вместо поиска в открытых источниках (§08.20.8) · **чужая регистрация (№ КУСП, ОМВД) в преамбуле** — правило 25 · подписант взят из донора вместо матрицы (правило 2) · персональные данные фигуранта перенесены из донора (правило 28) · не указан почтовый адрес ВСУ для ответа (§08.00.3 п. 6).

**Гейт.** Что именно запрашивается и **не требует ли это суда** · номер и период · Адресат и по какому правилу он выбран (фиксированный / по месту жительства / по месту службы) · источник реквизитов · подписант · дата живой сверки формулы основания · **хвост по §08.30** стоит (три абзаца дословно + «Наш адрес»), донорских «В связи с изложенным и руководствуясь ст. 21, 38, 39 УПК… прошу направить…» и «Срок исполнения: до …» нет.

### 08.10.1. Применение

Для получения **базовой** информации:
- принадлежность абонентского номера;
- тарифный план;
- IMEI устройства (если предоставит без судебного решения).

**Внимание:** для получения **детализации соединений, локации, содержания SMS** требуется **судебное решение** по ст. 165 УПК РФ (ст. 186.1). ⚠ Граница «без суда» для IMEI и сведений о предыдущих абонентах номера (тайна связи, ст. 63 ФЗ «О связи») — вопрос на сверку, см. legal_flags.

### 08.10.2. Шаблон (базовый)

Адресат: «Руководителю {ПАО «МТС» / «ВымпелКом» (Билайн) / ПАО «МегаФон» / ООО «Т2 Мобайл» (Tele2)}».

Перечень:
1. Принадлежность абонентского номера +7 (___) ___-__-__.
2. Дата заключения договора.
3. Тарифный план.
4. Сведения о предыдущих абонентах номера.

Для **детализации** — отдельный запрос с судебным решением.

### ● Карточка жанра

**Маршрут.** Выбери локальный бланк по жанру и создай отдельную рабочую копию. Заполненный образец не является источником фактов нового дела.

**Комплект.** Входит в профиль розыска (§08.00.1). Смежное — поручение о производстве ОРМ (ч. 1 ст. 144 УПК) на стадии проверки, `references/23-genres-144-proverka.md` §23.02: это другой жанр и другой адресат — только орган, осуществляющий ОРД.

**⛔ Фатальные ошибки.** Запрос ушёл в управление вместо территориального отдела · подменяет собой поручение об ОРМ · Реквизиты адресата выдуманы вместо поиска в открытых источниках (§08.20.8) · **чужая регистрация (№ КУСП, ОМВД) в преамбуле** — правило 25 · подписант взят из донора вместо матрицы (правило 2) · персональные данные фигуранта перенесены из донора (правило 28) · не указан почтовый адрес ВСУ для ответа (§08.00.3 п. 6).

**Гейт.** Адресат и по какому правилу он выбран (фиксированный / по месту жительства / по месту службы) · источник реквизитов · подписант · дата живой сверки формулы основания · **хвост по §08.30** стоит (три абзаца дословно + «Наш адрес»), донорских «В связи с изложенным и руководствуясь ст. 21, 38, 39 УПК… прошу направить…» и «Срок исполнения: до …» нет.

### 08.11.1. Применение

Для получения материалов оперативно-розыскной деятельности, копий протоколов АП, иных документов из подразделений МВД.

### 08.11.2. Шаблон
