## 09.11. ЗАПОЛНЕНИЕ БЛАНКОВ (.DOCX)

> ⓘ Не жанр — техника заполнения .docx-бланков, общая для всех форм. Карточка жанра не требуется.

**На выходе нужен заполненный бланк ДСП, а не «лист заполнения».** Методические указания иногда предлагают отдавать «лист заполнения» (структурированный текст) для ручного переноса. На практике следователю нужен **готовый заполненный бланк** соответствующей формы (Ф-1, Ф-1.1, Ф-1.2, Ф-1.3, Ф-2, Ф-3, Ф-5, Ф-6) в формате ДСП, по карте ячеек. ⛔ Бланк под форму искать по карте **§09.09** — имя файла не совпадает с названием формы. Сначала клонируй донорский бланк формы и подставь значения по координатам ячеек (см. §09.00 п. 2, карты — в персональном слое), сохраняя вёрстку (см. правило клонирования и `replace_text_preserving_layout` в `references/11-workflows.md`), и только при отсутствии бланка отдавай «лист заполнения» как **запасной вариант**.

### 09.11.1. Запасной вариант — структурированный текст

Учитывая сложную табличную структуру Ф-карточек, при отсутствии донорского бланка:
1. Открыть имеющийся у пользователя шаблон (типографский бланк).
2. Заполнить только содержательные поля.
3. Распечатать и заверить подписями.

Поскольку шаблоны Ф-карточек — это табличные формы по ведомственной инструкции, **полная Python-генерация в формате make_docx невозможна** без доступа к исходному бланку. Поэтому:

- При наличии у пользователя бланка Ф-карточки в .docx — открывать существующий файл через `python-docx`, заполнять текстовые поля, сохранять копию.
- При отсутствии бланка — ассистент составляет содержательную часть в виде структурированного текста, который пользователь переносит в имеющийся бланк вручную.

Когда пользователь просит «заполни Ф-1» без донорского бланка — вернуть заполненный список полей в формате:

```

Раздел 1 (заполняется работником ВП — для справки):
```

### 09.12.3. Правила для дела с несколькими фигурантами/составами

- Одна Ф-1 на каждое преступление, одна Ф-1.2 на каждое лицо.
- Порядковый № преступления (Ф-1, 1.3) и № лица (Ф-1.2, 1.3) — сквозные по делу. В Ф-1.2 «номер преступления» (3.1) ссылается на порядковый № соответствующей Ф-1.
- Формат квалификации в карте: «статья ч. N п. «X»» — например «290 ч. 5 п. «в»», «291 ч. 4 п. «б»», «291.1 ч. 3».
- Заполнять программно — правкой текста существующей ячейки-ответа (последний абзац ячейки, над ним абзац-подпись 6 пт). Шрифт ячейки сохранять (10–16 пт). Карты собирать в один .docx с разрывом страницы между картами (например, 2 таблицы Ф-1 + 3 таблицы Ф-1.2).

> **Координатные карты ячеек** (какое поле в какой `[t][r][c]`) в ядро НЕ включены: доноры разных отделов расходятся (напр. квалификация Ф-1 у одного отдела в строке 25, у другого — 26). Свою карту брать ТОЛЬКО из своего донора через `make_statcards.py grid`/`verify` (§09.00 п. 2). Готовые карты донора — в персональном слое.
