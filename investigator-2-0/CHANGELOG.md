# История изменений Investigator 2.0

Записывать изменения поведения основного комплекта: дата → выявленная проблема → исправление → фактически выполненная проверка. Не переносить результаты испытаний прежнего владельца как результаты текущей версии. Частное замечание распространять только на те задачи, для которых оно действительно применимо. Новые записи добавлять сверху; это единственная история изменений комплекта.

## 2.0.1 — 09.10.2026 — Безопасный запуск и надёжность инструментов

Безопасный запуск:

- `run.py` без ведома пользователя устанавливал недостающие пакеты из PyPI, в том числе по вызову AI-помощника. Теперь по умолчанию ничего не устанавливается: при неготовом окружении выводится подсказка (`start.cmd` или `run.py --install`) и код 2. Установку разрешает только явный `--install`; прежний `--offline` принимается для совместимости. Помощнику запрещено добавлять `--install` без согласия пользователя.
- При пустом списке собственных путей PATH начинался с пустого элемента, то есть с текущей папки. Пустые элементы больше не добавляются.
- Токен Hugging Face можно было передать ключом `--hf-token`, и он оставался в списке процессов и истории PowerShell. Ключ удалён; токен берётся из Диспетчера учётных данных Windows или `HF_TOKEN`.
- `post_release_gvp.py` завершал все процессы Excel пользователя (`taskkill /IM`), `fill_formfields.py` мог завершить Word, открытый пользователем во время работы скрипта. Теперь снимается только собственный экземпляр по PID окна; если PID не определён, ничего не завершается. `check_skill.py` ловит `taskkill /IM` во всех формах записи.

Надёжность инструментов:

- `consistency_check.py` сверял удалённые правки и коды полей и давал ложные расхождения ФИО и дат. Удалённый текст и коды полей исключены, XML-сущности раскодируются.
- В запасном разборе `check_tom.py` шаблон `w:t` захватывал `w:tab`, и текст абзаца искажался. Шаблон исправлен.
- `ocr_smart.py` при заданном только начале диапазона распознавал разное число страниц в зависимости от движка. Диапазон единый: только начало — до конца документа; неверный диапазон — понятная ошибка.
- soffice, tesseract, утилиты poppler и marker могли зависнуть без диагностики. Добавлены таймауты с сообщением на русском; долгий OCR (ocrmypdf) и установщики не ограничены.
- При сбое сохранения `docx_edit.py` и `fix_statcard_font.py` оставляли временный `~edit_*.docx` в папке дела. Временный файл удаляется, оригинал не изменяется.
- `check_env.py` требовал компоненты всех наборов и после установки только базы всегда завершался ошибкой; подсказки вели на несуществующие пути. Теперь проверяются выбранные наборы (по отметкам установщика или `--profile`), остальные показываются как неустановленные без ошибки.
- Документация приведена к новому поведению; версия комплекта — 2.0.1.

Проверено: pytest на синтетических данных, включая новые тесты запуска, PATH, профилей `check_env.py`, диапазона OCR, разбора DOCX и удаления временных файлов. На реальном Word/Excel под Windows не проверялось; наличие `Application.Hwnd` в версии Office пользователя стоит подтвердить.

## 09.10.2026 — Предупреждения повторного испытания

- При повторном испытании релиза 08.10.2026 выявлены предупреждения. PyMuPDF импортируется через поддерживаемое имя модуля `pymupdf`; внутренний псевдоним `fitz` оставлен для совместимости вызовов.
- Чтение локального JSON профиля в генераторе DOCX использует контекстный менеджер и закрывает файл.
- Публичный README и описание редакции датированы 09.10.2026.

Проверено: добавлены регрессионные тесты на оба случая; итог — в `docs/VALIDATION.md`.

## 08.10.2026 — Обновление публичной версии

Сохранены восемь навыков и переносимый установщик Windows. Подключение личных образцов и реквизитов остаётся локальным.

- Общий модуль `03c-legal-grammar.md`: каталог Я01–Я12, режим проверки по заданию, последствия неоднозначного прочтения и форма замечания. Маршруты добавлены в основной и семь специальных навыков. Набор условных языковых примеров увеличен с 18 до 24; уточнены правила обвинения.
- `word_text.py` объединяет чтение Word для извлечения и поиска. Сохраняется порядок абзацев и таблиц. При непринятых вставках, удалениях, перемещениях и исправлениях форматирования чтение останавливается. Проверяются также колонтитулы и сноски. После явного выбора доступны current/original/marked без изменения исходного файла и без подтверждения согласования.
- `corpus_search.py` сообщает код 2 и неполноту при пропуске документов с исправлениями. Этот результат не подтверждает отсутствие сведений в деле.
- `ocr_smart.py` проверяет код Tesseract и наличие текстового результата. Сбой возвращает ошибку, успешная пустая страница отличается от сбоя; частичный текст не печатается как успешный результат всего запуска.
- `make_docx.py` поддерживает выбор угловика по структуре независимо от имени рабочей копии и явный `letterhead_profile`. Перед сборкой проверяется обязательное поле адресата справа. Частный бланк не опубликован.
- Добавлен переносимый CMD для локальной настройки доступа к модели. Токен в репозиторий не включён; принятие условий выполняет пользователь.
- Уточнена историческая ссылка на постановление Пленума. Применимая редакция нормы проверяется заново при работе с конкретным делом.
- В публичном справочнике аудио устранены частные примеры и утверждения об испытаниях на компьютере автора. Установщик, модели и окружение проверяются у каждого пользователя отдельно.

Проверено: синтетические документы и имитация отказов OCR, подробно — в `docs/VALIDATION.md`. Проверки не подтверждают качество распознавания реальной записи, юридическую достаточность обвинения или установку на чистой Windows.
