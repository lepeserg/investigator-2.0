# Следователь: процессуальные решения

Применяй [общую основу](../investigator-2-0/SKILL.md) и прочитай нужный [раздел жизненного цикла дела](../investigator-2-0/references/05-genres-lifecycle.md). Для продления доследственной проверки — [05b](../investigator-2-0/references/05b-prodlenie-proverki-krsp.md), для проверки сообщения о преступлении — [23](../investigator-2-0/references/23-genres-144-proverka.md), для мер пресечения и судебных ходатайств — [07d](../investigator-2-0/references/07d-mery-presecheniya.md).

## Обязательные проверки по задаче

1. До составления или содержательной проверки прочти целиком паспорт выбранного жанра; установи стадию, дату, основания, полномочия и подписанта.
2. Для поручения о стадии или комплекте составь перечень применимых документов, приложений, уведомлений, согласований и карточек по жанру; для одного документа лишь обозначь необходимые связанные результаты.
3. Перед выдачей сверь мотивировку, источники, сроки, реквизиты и фактическую готовность комплекта. После массовой правки повтори содержательную проверку; проект решения не отмечай как вынесенное решение.

Комплектность, связанный поиск, контроль после правок и статусы плана — по [общему рабочему порядку](../investigator-2-0/references/27-case-workflow.md). Уже выполненные проверки повторяй только при изменении их оснований; для узкой правки проверяй затронутую часть и целостность результата.


Установи дату и процессуальную стадию, компетенцию лица, которое принимает решение, текущее положение каждого участника, основание и подтверждающие материалы. Для срока построй календарь от процессуального события и прежних решений; не подставляй сегодняшнюю дату вместо даты решения. Для продления отдельно изложи сделанное, оставшиеся действия и конкретные причины незавершения. Для приостановления, возобновления, прекращения и выделения сверяй последствия для обвинения и движения дела.

Новое постановление подготовь по подходящему образцу, очищая данные другого дела; подписанное решение не исправляй как черновик. Состав комплекта, уведомления, согласования и сопроводительные документы определяй по выбранному жанру. Перед выдачей сверь мотивировку с материалами, действующую редакцию норм, сроки, подписанта и [общий контрольный лист](../investigator-2-0/references/17-verification-checklist.md).

Судебное разрешение на следственное действие готовь здесь совместно с условиями из `actions`; само действие и его протокол – в `actions`. Привлечение в качестве обвиняемого и изменение обвинения передай в `charging`. Не называй будущие уведомления, согласования и действия уже состоявшимися.

## Объявление состава следственной группы

Для соответствующего протокола прочитай [профильные правила](references/protokol-sledstvennaya-gruppa.md). Применяй подходящий локальный образец пользователя. Его форма не подтверждает состав группы, полномочия или факт ознакомления по новому делу.
