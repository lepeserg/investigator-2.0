# Установка компонентов на Windows

## Быстрый запуск

Распакуйте ZIP репозитория и дважды нажмите `start.cmd`. Откроется меню:

| Пункт | Назначение | Что подготавливается |
|---|---|---|
| 1 — Base | Анализ текста, создание и изменение DOCX | Python 3.12 x64, базовые библиотеки, восемь точек входа навыков |
| 2 — Documents | Преобразование документов и просмотр в PDF | База; LibreOffice, если Word не зарегистрирован и LibreOffice не найден |
| 3 — Scans / OCR | Распознавание сканов | База, Tesseract, OCRmyPDF, pypdfium2; языковые данные rus, eng, osd |
| 4 — Audio | Подготовка аудио и расшифровка | База, FFmpeg, WhisperX и его зависимости |
| 5 — All | Все перечисленные возможности | Объединение наборов 1–4 |
| 0 — Exit | Выход | Ничего не устанавливается |

Для большинства документов начните с **2**. При появлении сканов повторно запустите установщик и выберите **3**, для аудиозаписи — **4**. Выбор дополнительного набора сохраняет уже установленное окружение. Аудиобиблиотеки и модели могут занимать несколько гигабайт.

Если Python отсутствует, сначала появится предложение установить его: `Install Python for this user? [y/N]`. Введите `y` для продолжения. Затем установщик покажет выбранные Python-профили и недостающие системные программы. `Prepare the selected profile? [y/N]` — подтвердите `y` или откажитесь нажатием Enter. Это два самостоятельных этапа: отказ на втором не удаляет уже установленный Python.

Системные программы сначала устанавливаются только для текущего пользователя (`winget install --scope user`), без прав администратора. Только если WinGet сообщает, что у пакета нет установщика для текущего пользователя (код `0x8A150010`), установщик сообщит об этом и повторит обычную установку; любой другой сбой не повторяется. WinGet и сами установщики могут отдельно показать условия использования и запрос Windows на права администратора. Отказ или ошибка останавливают текущую настройку. Ранее успешно установленные компоненты остаются; устраните причину и повторите выбранный набор.

## Откуда загружаются компоненты

- Системные программы: каталог Microsoft WinGet, точные идентификаторы `Python.Python.3.12`, `TheDocumentFoundation.LibreOffice`, `tesseract-ocr.tesseract`, `Gyan.FFmpeg`. Версию выбирает действующий каталог; идентификаторы проверены 07.10.2026. Для установленных и доступных программ повторная установка не запускается.
- Python-библиотеки: PyPI, прямые версии из `requirements/*.txt`. Устанавливаются в `.venv` проекта. Адрес индекса не зашит в установщик: корпоративное зеркало или прокси из `pip.ini` либо `PIP_INDEX_URL` применяется автоматически. Дополнительный индекс (`extra-index-url`) из `pip.ini` тоже используется, поэтому указывайте там только доверенный корпоративный индекс: версии зафиксированы, но хеши файлов не проверяются. Для установки без сети заранее подготовьте папку с wheel-файлами и задайте `PIP_FIND_LINKS=<папка>` и `PIP_NO_INDEX=1`.
- Языковые данные Tesseract: официальный репозиторий [tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast/tree/87416418657359cb625c412a48b6e1d6d41c29bd), фиксированная ревизия и SHA-256 каждого файла. При отсутствии нужных языков они сохраняются в `runtime/tessdata` внутри проекта, без изменения системной папки Tesseract. Лицензия языковых данных — [Apache 2.0](https://github.com/tesseract-ocr/tessdata_fast/blob/87416418657359cb625c412a48b6e1d6d41c29bd/LICENSE).

Скрипт не отключает проверки контрольных сумм WinGet, не запускает загруженный текст как команды, не устанавливает драйверы видеокарты. Исходные материалы дела для настройки не нужны и установщиком не читаются.

Если `winget` отсутствует, установите или обновите **App Installer / Установщик приложений** по [ссылке Microsoft](https://aka.ms/getwinget), откройте новое окно и повторите запуск. На управляемом служебном компьютере установка может требовать участия администратора. Скрипт не меняет корпоративные политики. `start.cmd` задаёт ExecutionPolicy только своему процессу PowerShell; системная настройка не изменяется.

Основные источники: [команда WinGet install](https://learn.microsoft.com/en-us/windows/package-manager/winget/install), [установка OCRmyPDF](https://ocrmypdf.readthedocs.io/en/latest/installation.html). Ghostscript не входит в этот установщик: профиль OCR включает pypdfium2. Для отдельных режимов PDF/A и дополнительных преобразований может потребоваться Ghostscript или другой инструмент; это проверяется для выбранной операции.

## Повторный запуск и проверка

Выбрать набор без меню:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup-windows.ps1 -Profile ocr
```

Проверить наличие зависимостей без загрузки, установки, подключения навыков и изменения настроек:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup-windows.ps1 -Profile ocr -CheckOnly
```

Код возврата 0 означает прохождение проверок зависимостей выбранного набора; 1 — ошибка или недостающий компонент; 2 — отмена установки. Готовность моделей, качество распознавания и вёрстка документов этим кодом не подтверждаются. После успешной установки создаётся локальный `runtime/setup-report.json` с датой и результатом последней успешной установки выбранного набора. Старый отчёт не подтверждает состояние после последующих изменений окружения; повторите `-CheckOnly`.

Если вы устанавливаете программы в нестандартные папки, заполните `tools.extra_path` в `config.local.json`. Если задан `tools.tessdata_prefix` или переменная `TESSDATA_PREFIX`, они имеют приоритет над языками проекта. При отсутствии rus/eng/osd по явно указанному пути установщик сообщит об ошибке; исправьте путь или уберите явное переопределение.

Для работы со скриптами можно использовать Python окружения, даже если команда `py` недоступна:

```powershell
.\.venv\Scripts\python.exe run.py extract_docx.py "D:/Учебный проект/пример.docx"
```

`run.py` по умолчанию не устанавливает недостающие пакеты, а останавливается с подсказкой; установку разрешает только явный ключ `--install`. Прежний ключ `--offline` принимается для совместимости, но не сочетается с `--install`.

`check_env.py` без отметок установщика (`.venv/investigator-install.json`, `runtime/setup-report.json`) проверяет прежний полный набор: база, документы (на Windows — включая Word COM) и OCR. При наличии отметок или ключа `--profile` (можно несколько раз, `all` — все) проверяются только выбранные наборы; компоненты невыбранных выводятся как «не установлено» и на код возврата не влияют. Набор «документы» на Windows требует Word COM: LibreOffice не заменяет его для заполнения форм. Для проверки системных программ выбранного набора используйте `-CheckOnly`.

## Что требует отдельной настройки

- **Microsoft Word:** лицензия и установка пользователем. LibreOffice подходит для части преобразований, но не заменяет Word COM в инструментах, которые используют автоматизацию Word, в частности при заполнении полей форм и обработке отдельных статкарточек. Регистрация Word ещё не доказывает, что автоматизация и лицензия работают.
- **Модели распознавания речи:** могут загружаться при первом запуске соответствующей операции. Для разделения говорящих пользователь отдельно принимает условия модели и настраивает токен локально через `run.py setup_hf_access.py`. Установка профиля audio не принимает эти условия и не проверяет доступ к модели.
- **GPU/CUDA:** драйверы, совместимость и режим вычислений проверяются отдельно. Установщик не обещает ускорение на любой видеокарте.
- **Everything, Marker/Surya и специальные PDF-инструменты:** необязательные дополнительные средства, не включённые в автоматические наборы.
- **Codex:** устанавливается и авторизуется пользователем отдельно; проектные точки входа создаются после подготовки зависимостей.

## Проверенность

На текущей Windows проверены запуск через Windows PowerShell 5.1, режим проверки базы и тесты веток отмены, сбоя установки, неверной контрольной суммы и повторного использования загрузки. Установщик не запускался на чистой виртуальной машине; полный цикл WinGet, OCR и аудио на такой машине пока не подтверждён. Список программ в действующем каталоге и доступность сетевых источников могут измениться.
