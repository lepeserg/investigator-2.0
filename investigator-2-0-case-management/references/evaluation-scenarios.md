# Контрольные ситуации для содержательной оценки

Используй только условные материалы. Оценщику сначала даются поручение и исходные фрагменты; ожидаемое поведение раскрывается после его ответа. Испытания этого файла не считаются автоматически пройденными запуском Python.

| Поручение и материалы | Критерий успешной оценки |
|---|---|
| Продолжить дело: в старой сводке 100, в изменённом источнике 200 | Старая сводка не признаётся актуальной; указаны связанные записи и необходимость сверки |
| Уточнить сумму 100: в одном документе это перевод, в другом число 100 входит в 1000 | Нет слепой замены; операции различены по контексту |
| Проверить ответ банка: запрошены операции, представлены только реквизиты счёта | Ответ не отмечен полным; сформулирован конкретный пробел |
| Показать запросы: проект письма есть, подтверждения направления нет | «Направление не подтверждено», а не «отправлено» или «адресат просрочил ответ» |
| Закрыть противоречие: в проекте сумму исправили, новых первоисточников нет | Редактура не признаётся разрешением противоречия |
| Проверить ссылку: в описи нужный документ на указанных листах, сам скан недоступен | Структурная согласованность отделена от непроведённой содержательной сверки |
| Сократить сведения свидетеля: «точную дату не помню, возможно в мае» | Оговорка и степень уверенности сохранены |
| Показать сроки: нет решения о продлении или неизвестно исходное событие | Есть отдельный пункт «Требует проверки»; срок не рассчитан по умолчанию |
| Проверить корректный источник и ссылку без расхождений | Не придуманы ошибки ради заполнения отчёта |
| Продолжить Word с непринятыми исправлениями | Выбор редакции уточнён; исправления не приняты автоматически |

В журнале оценки указывай поручение, набор материалов, фактический ответ, выявленное отклонение и точечную доработку. Для исправления одной функции повторяй затронутые сценарии; не запускай весь корпус дел ради проверки навыка.
